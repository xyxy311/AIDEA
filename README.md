# AIDEA
[English](README.en.md)

---

这是一款具有 AI 功能的头脑风暴应用：用节点和连线表达想法，用画布组织和嵌套思路，并让 AI 辅助发散思维。

技术栈：Vue 3 + TypeScript + Electron

## 功能概况

目前，AIDEA 比较简陋，但基本功能都可以正常使用：

- **画布与节点**：节点的创建、编辑、删除、连线、嵌套、对齐网格、框选；撤销/重做完整覆盖（属性连续输入自动合并，复合操作入栈为单条历史）
- **内联视图与节点视图**：节点可展开为画布中嵌套的子画布（一层），也可切换进入节点视图专注编辑；支持多标签页快速切换
- **预设样式**：节点/连线预设独立管理，支持分组与筛选，`1-9` 快捷应用
- **可定制界面**：左侧活动栏 + 右侧多面板 dock，面板可拖拽排序、跨侧移动、收起/关闭；顶部图标按钮同样可拖拽自定义；布局改动持久化，也可一键恢复默认
- **导出导入文本**：可以把项目导出为文本文件，也可以把文本识别插入到项目中
- **网格模式**：节点对齐网格，只使用键盘即可进行常用操作
- **节点搜索**：按文本搜索并跳转定位
- **标签系统**：项目级标签定义，节点打标，可用于搜索过滤
- **节点引用**：文本中 `#名字` 定义可引用名，`@名字` 引用（主色高亮、自动补全、点击跳转）
- **AI 辅助发散**（内置插件）：基于当前视图/选中节点的空间布局生成上下文，调用大模型发散生成词，点击词即添加为节点
- **文件**：项目的新建、保存与加载
- **外观**：亮/暗主题；界面语言支持中文 / English（设置 → 外观）
- **插件系统**：功能经插件 SDK 注册（面板/顶栏按钮/设置栏目/右键菜单/快捷键/浮动层/模态），AI 功能即以插件形态实现

本人的实力和时间都很有限，项目大部分内容都由 AI 编写，本人做出的修改很少，所以整个项目可能有很浓烈的“AI味”，但是应用的基本功能都可以正常使用。你也可以自己扩展本应用。

## 快速开始

可以直接在 Release 页面中下载 Windows 版本的安装包。

```bash
# 要求 Node.js 20+。
# 安装依赖
npm install

# 启动开发服务
npm run dev

# 构建
npm run build

# 运行
npx electron .

# 打包（目前只有 Windows 版本）
npm run dist:win
# 打包后，会在 release 目录中生成安装包（NSIS 安装器）
```

## 多语言

目前 AIDEA 支持中文（内置）与英文（以外部语言包形式存在），切换入口在 **Settings（顶部齿轮图标） → Appearance → Language**。

添加新语言，详见参考文档 [`追加语言.md`](docs/追加语言.md)。


### AI 功能配置

AI 功能需要在**设置（顶部齿轮图标） → 插件** 中启用，然后重新加载。AI功能基于 OpenAI 兼容接口，使用前需要先配置连接参数：

1. 打开 **设置 → AI 设置**；
2. 填写 `baseURL`、`model`、`apiKey`（可调超时与温度）；
3. 在面板中选中节点后按 **`I`** 直接发散，**`C`** 清除生成词；也可在 AI 面板中调整全局/视图级提示词、发散方向与生成模式。

连接配置保存在应用本地（不随项目文件），项目级提示词随项目文件保存。

## 数据存储位置

- **用户配置**（主题/主色/语言/快捷键/面板拖拽/预设样式/插件启停与配置/最近文件…）：保存在应用的**用户数据目录**（Electron `userData`），由 `app.setName('AIDEA')` 固定，Windows 上为 `%APPDATA%\AIDEA\`（即 `C:\Users\<用户名>\AppData\Roaming\AIDEA`），插件和语言包也存放在此目录中的对应位置。
- **项目内容**：保存在 `.aidea.json` 项目文件中，由你通过「打开/另存」自由选择路径，不写入用户数据目录。

## 项目结构

```
AIDEA/
├─ electron/           Electron 壳：main / preload / shared（IPC 桥、插件协议、种子复制…）
├─ src/                渲染层（Vue 3 + TypeScript）
│   ├─ components/     画布 / 顶部栏 / 面板 / 布局 / 通用组件
│   ├─ composables/    命令层 useCommands、useActiveView、useT…
│   ├─ stores/         pinia：node / tag / view / project / preset / history / theme…
│   ├─ config/         配色 colorSchemes（亮/暗 + 主色）
│   ├─ constants/      设计 token 与品类表（面板/顶栏按钮注册）
│   ├─ locales/        内置中文文案
│   └─ utils/          纯函数
├─ plugins/            插件（内置 AI 发散）
├─ i18n-runtime/       运行时语言包目录（dev：`*.json` 热登记）
├─ scripts/            构建脚本（dev / build-electron / vendor…）
├─ build/              electron-builder 资源（图标、NSIS 脚本）
├─ docs/               架构与使用文档
├─ public/             静态资源
└─ test/               测试
```

核心架构采用三层：**交互层 → 命令层（useCommands）→ 数据层（stores）**。所有数据写操作经 `useCommands` 捕获旧值、生成 `DataPatch` 并入历史栈，这是撤销/重做可靠性的基础。详见 `docs/` 下的文档。
