# 顶部栏按钮注册与拖拽（LeftTopBar + RightTopBar）

顶部 `LeftTopBar` / `RightTopBar` 是原「菜单栏 MenuBar / 工具栏 Toolbar」的更名版本。按钮走**「品类表注册（`constants/topbar.ts`）+ uiRegistry 登记 + layout delta 派生」**统一机制：新增按钮只登记品类表并给一个按钮逻辑组件，左/右顶部条渲染、同侧换位、跨区放置、默认布局全部自动生效。视觉外壳统一由通用模板 `TopBarButton` 提供，按钮逻辑组件只暴露状态与点击。机制完全模仿左右侧边栏（`Panel` 品类表）的注册与拖拽设计。

## 相关文件

| 文件 | 职责 |

## 关键类型和函数

**`constants/topbar.ts`**
```ts
interface TopBarDef {
  id: TopBarId
  titleKey: string             // 标题 i18n key
  defaultZone: 'left'|'right'  // 默认放置侧
  component: Component         // 按钮逻辑组件（视觉外壳由 TopBarButton 提供）
}
const TOP_BAR_CATALOG: TopBarDef[]   // 全量品类表，不区分左右
```
派生导出 `TOP_BAR_INDEX`（id→def）、`TOP_BAR_COMPONENTS`（id→组件）、`DEFAULT_LEFT_TOP`/`DEFAULT_RIGHT_TOP`（按 `defaultZone` 派生）。类型 `TopBarId` / `PluginTopBarKey`（`${pluginId}:${id}`）/ `TopBarKey = TopBarId | PluginTopBarKey` / `TopBarZone = 'left'|'right'`。

**`utils/topbar.ts`**（纯函数）
- `parseTopDelta(raw, isKnown)`：解析 localStorage 顶栏 delta（过滤非字符串/未知/重复项，返回 `TopDelta`）。
- `deriveTopLayout(defs: ZoneDef[], delta)`: `TopPlacement`：归属 = 用户顺序命中（右优先）否则 `defaultZone`；顺序 = 用户顺序优先，其余按登记追加。
- 拖拽协议：`TOP_DRAG_MIME = 'aidea-topbar'`、`writeTopBarDrag(e, {buttonId, zone})`、`readTopBarDrag(e)`（解析失败返回 null）。
- `reorderSeq` 复用 `utils/dock.ts`（面板与按钮同一换位语义）。

**layout store**：派生目录 `topLeft`/`topRight`（`UiTopBarEntry[]`，含 component）；动作 `reorderTop(zone, from, to)` / `moveTopZone(id, toZone)` / `resetTopBar()`。

## 模块内部组织关系和调用链

```
按钮注册
  ├─ 内置：constants/topbar.ts (TOP_BAR_CATALOG) 登记 → uiRegistry seed →
  │         提供 components/topbar/*.vue 逻辑组件
  └─ 插件：registerPluginTopBarButton → uiRegistry（组件经 wrapTopBarButton 包装）
        ↓
layout delta 派生 topLeft / topRight（deriveTopLayout(登记表, delta)）
        ↓
LeftTopBar / RightTopBar → TopBarZone(zone) → 按目录渲染 <component :is="entry.component">
        ↑ 外壳由 TopBarButton 提供，item 上挂 draggable
```

- **同侧换位**：拖到同侧另一位置 → `layout.reorderTop(zone, from, to)`。
- **跨区移动**：item `dragstart` 写 `{buttonId, zone}`（`TOP_DRAG_MIME`）→ 目标容器 `dragover/drop` 经 `readTopBarDrag` 判断 `data.zone !== props.zone` → `layout.moveTopZone(buttonId, toZone)`（源侧移除 + 目标侧末尾追加）。

## 实现细节和踩坑点

- **抑制拖拽后误触 click**：item 的 `dragstart` 置 `suppressClick=true`，`dragend`/`drop` 的 `endDrag()` 用 `setTimeout(0)` 复位；item 以 `@click.capture` 捕获时若 `suppressClick` 为真则 `stopPropagation`+`preventDefault`，避免拖拽结束顺带触发按钮动作。
- **跨区 dataTransfer MIME**：跨侧投放必须读 `TOP_DRAG_MIME`（`aidea-topbar`）且校验 `data.buttonId === string`、`data.zone !== 本侧`，避免把同侧换位误判为跨区；写前容错缺省 `dataTransfer`（`if (e.dataTransfer)`）。
- **window drag 区**：`top-item` 设 `-webkit-app-region: no-drag`，防止 app 窗口整条可拖动时抢占按钮点击与 HTML5 拖拽。
- **resetDock 内含 resetTopBar**：设置「恢复默认布局」调 `layout.resetDock()`（清空左右侧边栏全部 delta）→ `resetTopBar()` 删除 `aidea-top-left`/`aidea-top-right` 并清空顺序，两侧回退到登记默认。顶栏只持久化顺序 delta，新增内置按钮/插件按钮自动出现在默认侧。
