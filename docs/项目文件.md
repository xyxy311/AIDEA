# 项目文件（新建 / 保存 / 打开）

应用支持新建、保存、打开项目，可自定义保存文件位置。文件为 JSON 带版本号格式（`.aidea.json`）。

## 功能行为

- **新建项目**：清空当前树为「未命名项目」根节点，清空撤销栈与视图状态。
- **保存**：序列化当前节点树 + 项目名 + 视图状态为 JSON 并写入文件。
- **打开项目**：读取本地 JSON 文件并载入，替换当前树、清空撤销栈、恢复视图状态。
- **保存位置**：Electron 原生对话框（纯桌面形态）。文件位置与磁盘读写全部由 main 进程（`dialog` + `fs`）完成，renderer 经 `window.aideaFile` 桥调用：打开/另存时 main 弹原生 `showOpenDialog` / `showSaveDialog` 选真实文件位置；打开后记忆**磁盘路径**，`Ctrl+S` 直接覆盖原文件，无需再选。（浏览器 File System Access API / `<input type=file>` / Blob 下载兜底已随纯桌面收敛移除。）
- **脏检查**：有未保存改动时，新建/打开前弹确认，关闭/刷新前 `beforeunload` 提示。

## 文件格式

```jsonc
{
  "version": 1,
  "projectName": "项目名",            // 根节点 text
  "nodes": [ /* WhiteboardNode[]，含根节点 id='root' parentId=null；节点含 tagIds 字段 */ ],
  "tags": [ { "id": "...", "name": "标签名", "color": "#4fc3f7" } ], // 项目级标签定义
  "viewState": {
    "viewedNodeId": "root",          // 主视图当前查看节点
    "stageX": 0, "stageY": 0, "stageScale": 1,
    "expandedIds": ["root"],         // 树展开
    "inlineViews": [{ "nodeId": "...", "width": 400, "height": 300 }], // 内联视图展开（只存 nodeId+尺寸，viewId 是运行期实例不落盘）
    "selectedNodeIds": [ ],
    "selectedConnectionIds": [ ]
  }
}
```

- `childrenIndex` / `referenceIndex` / `tagIndex` 是 computed 派生索引，**不落盘**。
- 连线嵌套在父节点 `connections`，随节点一起序列化。
- 标签定义 `tags` 与节点 `tagIds` 均为**可选字段**（版本保持 1 前向兼容）：旧文件缺失时解析补 `[]`；`parseProjectFile` 会把节点 `tagIds` 裁剪为仅存在于 `tags` 定义内的 id（自愈悬空引用）。

## 架构

```
utils/projectFile.ts              # 序列化/解析纯函数（不依赖 store）
stores/file.ts                    # dirty / suggestedName / savedPath 状态
stores/recentFiles.ts             # 最近文件：name + path（路径式，磁盘归 main）
composables/useProjectFile.ts     # 编排层：new/open/save/saveAs + 原生对话框交互
composables/useNativeFile.ts      # window.aideaFile 桥唯一 renderer 访问点
composables/useKeyboardShortcuts.ts # Ctrl+S/O/N
components/layout/AppShell.vue    # NDialog 确认 + beforeunload + 快捷键挂载
```

### utils/projectFile.ts

| 函数 | 作用 |
| --- | --- |
| `serializeProject(nodes, projectName, viewState, tags)` | 组装带 `version` 的 JSON 字符串（含标签定义 `tags`） |
| `parseProjectFile(json)` | 解析并校验：版本兼容、过滤非法节点/连线、根节点兜底、viewState 逐字段校验 |

- 版本不匹配抛「文件版本 {v} 不受支持」。
- 缺根节点时用 `createNode` 补一个（`id='root'`）。
- 连线两端不在节点集合内 → 剔除。
- `selectedNodeIds` / `inlineViews` 中不存在的节点 → 过滤。

### composables/useProjectFile.ts

核心是 `loadProjectIntoApp(data)`，新建 / 打开共用：

```
nodeStore.replaceNodes(整树)   # 整树替换（nodeStore 新增 action，bypass 历史栈）
tagsStore.replaceTags(tags)     # 载入项目级标签定义（新建时 data.tags 缺失 → [] 兜底清空）
commands.clearHistory()        # 清空撤销栈
project.resetForNewProject()   # 清 viewSnapshots / expandedIds / 销毁内联视图 / 重置主视图
恢复视图状态                    # 展开态 → switchView(root) 归位 → switchView(目标) → 视口 → 重建内联视图 → 选中 prune
```

- **路径记忆**：`saveProject` 若 `fileStore.savedPath` 存在则经桥 `writeFile` 覆盖；否则走 `saveAsProject`（main `showSaveDialog` + `writeFile` → 记录 path）。`openProject` / `openRecentFile` 载入时一并 `setSavedPath(path)`，使打开后 Ctrl+S 直接覆盖同一文件。
- **主进程职责**：`electron/main/ipc.ts` 注册 `file:open` / `file:save` / `file:write` / `file:read` 通道（preload 暴露为 `window.aideaFile`）；renderer 不传任意路径——打开/另存由 main 对话框定路径，覆盖/重读仅回传 renderer 自持的最近/记忆路径。
- **取消不报错**：桥返回 `{ canceled: true }` 静默返回；仅真实解析/写入失败弹错误提示。

## dirty 判定

```
完成的数据写入（history.pushCommand / undo / redo）
    → utils/dirtyMarker.markDataDirty()
    → fileStore.dirty = true
```

- `utils/dirtyMarker.ts` 是模块级回调注册，解耦 history ↔ file store（避免循环依赖）。
- `loadProjectIntoApp` 用 `replaceNodes` 直改数据（不走 pushCommand），**不误置 dirty**；载入后由调用方 `markClean()`。
- 实时渲染（拖拽 mousemove / resize transform）不入栈，但结束事件 `commit*` 入栈时会置 dirty。

## 交互接入

- **菜单栏**（MenuBar）：文件菜单「新建项目 / 打开项目 / 保存」，经 `inject('projectFile')` 调编排层（AppShell 单实例 + provide）。
- **快捷键**：`Ctrl/Cmd+S` 保存、`Ctrl/Cmd+O` 打开、`Ctrl/Cmd+N` 新建（`useKeyboardShortcuts`，AppShell 单份挂载，`preventDefault` 拦截浏览器默认）。
- **确认对话框**：AppShell `useDialog` 构建 `confirm(message)`，dirty 时新建/打开前调用；`App.vue` 需包 `NDialogProvider`。
- **关闭提示**：AppShell `beforeunload` 在 `fileStore.dirty` 时设置 `returnValue`。

`npm run type-check` 零错误 + `npm run test` 全绿。文件选择/读写为 Electron 主进程对话框行为，agent 无法在自动化中触发；实际保存/打开体验需人工在 Electron 窗口验证（`npm run dev`）。
