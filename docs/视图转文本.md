# 视图转文本

把「视图节点」按空间位置编排成格式化文本，供 AI / 其它给 AI 提供项目上下文的函数理解项目内容。该能力随 AI 功能迁移为内置插件（`plugins/ai/`），实现位于插件目录内。

## 用途

- 视图 = 某节点（当前视图的 `viewedNodeId`）的直接子级，即画布上渲染的节点。
- 把二维布局降维成有结构的文本：纵向分「行」、行内按横向排序，帮助 AI 感知节点的空间关系。
- 作为 AI 上下文的**唯一来源**：`plugins/ai/composables/useAIWordPanel.ts` 的 `directGenerate()` 在预览为空时调用 `buildViewText` 自动生成上下文预览。
- AI 面板提供算法选择与参数调整。

## 架构：策略模式 + 算法注册表

算法定义在 `plugins/ai/utils/viewText.ts`，为「自带参数 schema + 构建函数」的自描述对象：

```ts
interface ViewTextAlgorithm {
  id: string
  labelKey: string                 // 算法显示名 i18n key（主程序 locales，插件经 t() 消费）
  params: ViewTextParamSchema[]    // 参数 schema（面板据此动态渲染控件）
  build(nodes, params): string
}
```

- 面板只读注册表 `VIEW_TEXT_ALGORITHMS`，动态渲染算法下拉与参数控件，调用统一调度器 `buildViewText`。
- **替换 / 新增算法**只需在注册表追加一个 `ViewTextAlgorithm` 对象，面板零改动（下拉选项、参数控件自动出现）。

## 当前算法

### 行聚类（rowCluster）

参数：

| schema key | 类型    | 默认    | 说明 |
|---|---|---|---|
| `tolerance`   | number  | `10`    | 纵向聚行容差（px），用于归并视觉对齐但有微小间隙的节点 |
| `includeCoords` | boolean | `false` | 行内每项是否带 `[x,y]` 前缀 |
| `separator`   | select  | `'\t'`  | 行内连接符（制表符 / 逗号 / 分号 / 竖线） |

流程：
1. 节点按 `y` 升序排序。
2. 贪心聚行：节点与已有行的纵向区间重叠（含 `tolerance` 容差）则并入该行并扩展区间，否则新建行。
3. 每行内按 `x` 升序排序，用 `separator` 拼接；行间用 `\n` 拼接。

### 直线命中（lineHit）

以节点包围盒中心点连线做纵向区间命中判断，参数含 `yThreshold` / `offset` / `overlapRatio` / `includeCoords` / `separator`。

### 直接收集（collectAll，默认）

忽略空间位置，按数组顺序逐行收集；可选 `includeCoords` 带坐标前缀。

保证每个节点恰好出现一次，无去重歧义、无步长魔法参数。

## 文件

- `plugins/ai/utils/viewText.ts` — 纯函数 + 算法注册表 + 调度器（可单测，不依赖 store）
- `plugins/ai/components/AIPanel.vue` — 算法下拉与参数控件消费方（原独立 ViewTextPanel 已移除，能力并入 AI 面板）
- `plugins/ai/composables/useAIWordPanel.ts` — 上下文预览生成调用方（`buildViewText`）
- `plugins/ai/index.ts` — 插件注册（AI 面板经 `ctx.register.registerPanel` 登记进 uiRegistry）
- `src/locales/zh-CN.json` — UI 文案（`viewTextPanel.*` key，经主程序 i18n 占位层供插件 `t()` 使用）
- `plugins/ai/__tests__/viewText.test.ts` — 算法与调度器单测

## 布局补充逻辑

layout store 采用 **delta 排布模型**：localStorage 只存用户显式排布改动，渲染目录 = `deriveDockLayout(uiRegistry 登记表, delta)`（`src/utils/dock.ts`）实时派生——插件注册的面板自动按 `defaultPlacement` 出现在对应侧，
保证新增面板（内置或插件）无需手动落位即可对已有用户生效。
