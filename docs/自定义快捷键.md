# 自定义快捷键

在设置面板「快捷键」分类中，用户可重绑部分动作并配置「序号修饰键」。架构根基是**规范化 chord 字符串即等价判定** + **单一运行时 Map**。

## 核心架构

- **字符串即等价判定**（`utils/shortcuts.ts`）：所有快捷键表示为规范化 chord 字符串，修饰键按固定顺序 `mod > alt > shift` 拼接，`mod` = Ctrl 或 Meta(Cmd)。例：`a`、`mod+s`、`mod+shift+z`、`alt+1`、`tab`、`delete`。一个字符串唯一对应一种按键组合，可直接作 Map 的 key。
- **单一运行时 Map**（`composables/useKeyboardShortcuts.ts`）：`useKeyboardShortcuts` 把锁定键 + 可改动作压成 `Map<chord, { id, scope, run }>`。keydown 时 `toChordString(e)` O(1) 查表，锁定的 `1-9`、剪贴板、撤销等与可改动作同进一表——结构上保证一按键至多命中一个动作，杜绝双触发。
- **scope 决定触发时机**：`'always'`（保存/打开/新建/搜索）在输入框/编辑守卫之前执行，编辑中也可用；`'canvas'`（其余）在守卫（`HTMLInputElement`/`HTMLTextAreaElement` + `isEditing`）之后执行。scope 定义见 `types/shortcuts.ts` 的 `ShortcutScope = 'always' | 'canvas'`。

## 关键类型和函数

- **类型**：`ShortcutScope`（`'always' | 'canvas'`）；`ShortcutChord`（`{ key, mod, alt, shift }`，解析结果）。
- **常量**（`constants/shortcuts.ts`）：`CUSTOM_SHORTCUTS`（10 个可改动作，含 `save/open/new/search`→always 与 `group/enterChild/enterParent/toggleInline/fitInline/deleteSelected`→canvas）；`RESERVED_CHORDS`（撤销/重做、剪贴板、`delete`/`backspace`、`escape`、方向键、`enter`、数字 `1-9`，不可被占用）；`DEFAULT_SEQ_MOD_KEY`（`'t'`）。
- **utils 纯函数**（`utils/shortcuts.ts`）：`normalizeKey`（键名小写 + 别名表）；`toChordString(e)`（事件→序列化串，Ctrl/Meta 归一为 mod）；`isValidChord`（末位须独立键，前缀仅 mod/alt/shift）；`parseChord`（串→`ShortcutChord`）；`formatChord`（平台化展示，Mac 用 ⌘/⌥/⇧）；另有 `isModifierOnly`。
- **shortcuts store**（`stores/shortcuts.ts`）：`overrides` / `seqModKey`（localStorage 持久化 + 自愈）；`bindings`（默认之上覆盖优先，pluginConfig 插件覆盖拼完整 key 后并入）；`assign`（冲突校验 + 存储路由：内置写 `overrides`、含 `:` 的插件动作写 pluginConfig）；`setSeqModKey` / `reset` / `resetAll`。
- **runtimeMap**（`useKeyboardShortcuts`）：computed `Map`，`getBinding()` 取串查表分发；`seqHeld` 记录序修饰键按下态。

## 模块内部组织关系和调用链

```
可改动作（内置 CUSTOM_SHORTCUTS + 插件 registerShortcutAction 进 uiRegistry.shortcutActions）
        → shortcuts store bindings 合并（默认 + 覆盖，插件覆盖存各插件配置文件 shortcuts 段）
        → runtimeMap（锁定 + 可改 + 插件，按 scope 分发）
```

- **序号修饰键**：按住 `seqModKey`（默认 `t`）再按 `1-9` → 对选中节点批量打/删标签；直接按 `1-9` → 应用当前筛选下可见预设（节点优先，其次连线）。序键必须为单个普通键（非数字、非组合）。
- **冲突检测**：`assign(id, chord)` 校验非法输入 / 与锁定键 `RESERVED_CHORDS` / 与序号修饰键（裸单键）/ 与其它动作（内置 `getBinding` + `uiRegistry.shortcutActions`）→ 冲突拒绝，返回 `{ ok, conflict }`。插件 `defaultChord` 注册时同样校验。

## 实现细节和踩坑点

- **持久化与自愈**：`localStorage('aidea-shortcuts')` 仅存被改动项，加载时丢弃非法值与相互冲突的重复键（保留先到）；`localStorage('aidea-shortcuts-seqmod')` 非法回退 `t`。加载前先 `migrateShortcutOverrides()`，把历史混存的内置区插件条目搬入各插件配置文件。
- **序号修饰键默认 `t`**：独立于动作注册表存于 `seqModKey`，可改；录制候选须为非修饰、不含 `1-9` 的裸单键。
- **按键录制**：`ShortcutsSection.vue` 在 `window.addEventListener('keydown', onCaptureKeydown, true)` 捕获阶段监听并 `stopImmediatePropagation`，避免录制时误触全局快捷键（网格层同用 stopImmediatePropagation = 独占）。`ShortcutActionRow` 提供行级录制与单行恢复默认。
- **插件命名空间覆盖**：插件动作 key = `${pluginId}:${actionId}`，覆盖独立存于各插件配置文件 `shortcuts` 段；插件禁用/重装后覆盖保留。自愈对含 `:` 的命名空间覆盖跳过清理，重装恢复。

> 说明：`deleteSelected` 默认绑定字母 `d`（可重绑），但 `delete`/`backspace` 本体固定锁定，二者并存。

新增可自定义动作：在 `CUSTOM_SHORTCUTS` 追加一项 + 在 `customRuns` 补 run；插件经 `ctx.register.registerShortcutAction` 注册（见 `插件系统.md`、`插件UI注册.md`）。
