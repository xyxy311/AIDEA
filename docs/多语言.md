# 多语言

## 核心架构

i18n 是轻量占位层，未用 vue-i18n。入口 `composables/useT.ts`：导出全局 `t(key, params?)`，未命中回退链 `当前语言 → zh-CN → key`。核心是 `createT(source)` 工厂，宿主全局 `t` 与插件语言包共用同一实现——未来迁移 vue-i18n 只需改 `useT.ts` 内部。

### 内置 vs 运行时

- **内置种子**：仅 `zh-CN` 编译期内置（`src/locales/zh-CN.json`，含 `@meta`），永远兜底、不可删除。种子表在 `constants/locale.ts` 的 `LOCALE_ENTRIES`（单一数据源）。
- **运行时语言**：把规范语言包（`.json` + 自描述 `@meta` 头）放进**运行时 i18n 目录**即自动登记，无需改码、无需重启（目录监听热登记）。目录：dev 为 `<仓库根>/i18n-runtime/`，生产为 `userData/i18n/`。`i18n-runtime/en-US.json` 是内置样例与功能测试夹具。

### 语言包自描述 `@meta`

```jsonc
{
  "@meta": { "id": "en-US", "label": "English", "naiveBase": "en-US" },
  "menuBar": { "file": "File" }
}
```

- `id`：语言标识，须与文件名（去 `.json`）一致，强校验 `^[a-zA-Z0-9_-]+$`。
- `label`：语言自名（不翻译、不走 `t()`），供下拉展示。
- `naiveBase`：naive-ui 文案兜底语言 id，缺省 `en-US`。
- 内置 `zh-CN` 同样带 `@meta`，与追加语言走同一解析管线。

### 数据流

```
i18n-runtime/*.json
   └─ main(i18nScan/i18nWatch) ──IPC(I18N_LIST/READ/CHANGED)── preload aideaI18n ── i18n/loader.ts
        → i18nStore(registerPackage / available / readBundles)
             → useT.t()（createT getter 读响应式 store，热登记即时生效）
             → 语言下拉（AppearanceSection）
             → App.vue 的 naive :locale/:date-locale（按当前语言 naiveBase 映射）
```

## 关键函数

- **`createT(source)`** → 返回 `t(key, params?)`。`source` 可为静态文案表集合（插件）或返回集合的 **getter 函数**（宿主从响应式 `i18nStore` 读取，热登记/热替换即时生效）。产物回退链：`bundles[当前语言]` → `bundles['zh-CN']` → 返回 key 本身。
- **`i18nStore`**（`stores/i18n.ts`）：`available`（下拉数据源）、`registerPackage(id, bundle)`（校验 `@meta` 并登记/覆盖）、`unregisterPackage(id)`（内置 `zh-CN` 不可注销）、`readBundles()`。
- **`getLocale()`**：读 `themeStore.locale`（`useStorage('aidea-locale')`，默认 `DEFAULT_LOCALE`=`zh-CN`）；pinia 未就绪回退 `zh-CN`。
- **响应式依赖**：`getLocale()`/`t()` 在 **computed / 模板内**调用即建立响应式依赖，切语言或热登记热更新。

## 用法与约定

- **所有用户可见 UI 文本必须经 `t()`**，禁止硬编码中文；新增文本同步加 key（并保持各语言包 key 对齐，`parity.test.ts` 守护）。
- `{name}` 插值：`t('key', { name })`，占位符逐个替换。
- naive-ui 组件内部文案/日期**不复刻**进自编 locale：语言包只声明 `naiveBase`，`App.vue` 运行时把它映射到 naive 自带 `NLocale`（未内置则按 `en-US` 兜底，见 `composables/naiveLocale.ts`）。
- 插件文案不进宿主 locales：多语言插件在 `plugins/<name>/locales/` 自备语言包，经 `adapter.api.i18n.createT()` 得到自己的 t（见 `插件开发手册.md` 4.10）。
- **响应式约定**：`t()` / `getLocale()` / `createT` 产物必须在模板或 computed 中调用（内部读 themeStore.locale / i18nStore.bundles 建立依赖），禁止把调用结果赋给模块级常量（会固化首次语言）。

> 向正式版追加语言、语言包编写规范与即插即用用法，见 `docs/追加语言.md`。
