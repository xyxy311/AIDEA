# 标签系统

## 核心架构

- **标签是项目级数据**：定义存 `stores/tags.ts` 的 `tags: reactive(Map<tagId, Tag>)`，随项目文件序列化，区别于 localStorage 的全局预设 presets。删除标签时反向清关联（`deleteTag` → `nodeStore.stripTagFromAllNodes`）。单向依赖 nodeStore（nodeStore 不 import 本 store，无循环依赖）。
- **节点关联内联**：节点加 `tagIds: string[]` 字段（引用标签定义 id），与 `connections` 同为节点内字段，删除/复制/组合/迁移子树时随之自然迁移。
- **反向索引**：`nodeStore.tagIndex` 为 computed 派生（`tagId -> nodeId[]`，仿 `referenceIndex`），供标签面板与搜索做反向查询。
- **关键约束——撤销边界**：标签定义 CRUD（新建/改名/改色/删除）**不可撤销**，直接改 Map + `markDataDirty()`，不经命令层；仅「节点打标签」走命令层 `useCommands.updateNodesTagsPerNode`（`nodeChanges.modify.tagIds`，coalesceKey `tags-${sortedKey}`）可撤销。因而不新增 `tagChanges` 通道、不改 `history.ts`。

## 关键类型和函数

```ts
Tag = { id: string; name: string; color: string }
```

- `updateNodesTagsPerNode(ids, tagIdsPerNode)`：`ids` 与 `tagIdsPerNode` 等长，逐节点整体替换为该节点自己的标签集合（`[...new Set(...)]`），改后 `fitNodeToText`；coalesceKey `tags-${sortedKey}` 合并连续编辑，入历史栈。
- `updateSelectedNodesTags(ids, tagIds)`：给所有目标节点设同一组标签，委托 `updateNodesTagsPerNode(ids, ids.map(() => tagIds))`。
- `stripTagFromAllNodes(tagId)`：`deleteTag` 时经 `tagIndex` 找到所有相关节点并从其 `tagIds` 移除。
- `tagIndex`：`nodeStore` 的 computed 反向索引（`Map<tagId, nodeId[]>`）。
- `tagsStore.getTag(id): Tag | undefined`：查询定义；**所有消费 `tagIds` 处用它过滤 undefined**。

## 模块内部组织关系和调用链

- **打标签入口**：属性面板（`NodePropertyEditor` 多选交集 NSelect）/ 标签面板 / 快捷键 `T+1-9`（全含该标签则移除、否则添加，各节点保留自有其它标签）→ `useActiveView.updateSelectedNodesTagsPerNode` → `useCommands.updateNodesTagsPerNode` 捕获旧 tagIds → `nodeStore.updateNodesTagsPerNode` 写入 + `fitNodeToText` → `history.pushCommand`（modify）。
- **删除标签**：`tagsStore.deleteTag` 删定义 + `stripTagFromAllNodes` 清所有节点关联（`markDataDirty`，不入 undo）。
- **悬空引用容错**：#trigger 两个摩擦源之后——消费点 `getTag` 过滤 undefined（渲染胶囊、属性下拉、搜索）；持久化侧 `parseProjectFile` 用 `tagById.has` 裁剪非存在 id，缺失兜底 `[]`。

## 实现细节和踩坑点

- **胶囊渲染**（`WhiteboardNode.vue`）：节点右下角、从右往左贪婪右对齐摆放，最多 `TAG_CAPSULE_MAX`(4) 个 + 溢出 `+N`；胶囊 `listening: false` 不拦截事件，不挡拖动/选中/双击/引用点击。
- **文本预留公式**：`reservedBottom = NODE_PADDING + TAG_CAPSULE_HEIGHT + TAG_CAPSULE_BOTTOM_GAP`（有标签时），`WhiteboardNode.layoutLines` 与 `nodeStore.fitNodeToText` 同式，`updateNodesTagsPerNode` 写后调 `fitNodeToText` 扩张高度；注：`fitNodeToText` 只扩大不缩小，取消标签不会缩小已扩大的高度（无害）。
- **NColorPicker 色点撑满的 `#trigger` 处理**（`TagsPanel.vue`/`NodeItem.vue`）：NColorPicker 根自带 `width:100%`，直接内联会撑满 flex 行；用 `#trigger` 插槽渲染固定尺寸（14px）纯色圆点，顶部取色块用 `flex: 0 0 40px` 强制固定。
- **撤销跨删除标签边界的悬空引用（重要坑）**：定义不可撤销 + 打标签可撤销的张力下，undo 跨「已删除标签」边界会用旧 `tagIds` 恢复出已删标签 id（悬空引用）。**所有消费 `tagIds` 处都必须 `getTag(id)` 过滤 undefined**，并由 `parseProjectFile` 裁剪自愈——否则渲染/搜索/属性面板会出现无效 chip 或错误匹配。
- **胶囊颜色**：`Tag.color` 是数据色（不随主题）；溢出胶囊与胶囊文字对比色（WCAG 亮度）随主题。

> 序列化/文案/测试细节一律压缩：`ProjectFileData`/`ParsedProject` 含 `tags: Tag[]`，`tagIds` 随节点序列化，版本 1 前向兼容（旧文件补 `[]`）；UI 文案走 `t()`（`leftSidebar.tags/searchTagPlaceholder`、`nodeEditor.tags*`、`tagsPanel.*`）；`search.test.ts` 覆盖单标签/多标签 AND/空过滤/与关键字叠加/悬空 `tagIds?.` 容错。
