# 画布与渲染

## 核心架构

`src/components/canvas/` 负责画布渲染。`WhiteboardCanvas` 是主视图入口（viewId 固定 `'main'`），实际工作是通用组件 `CanvasStage`（经 `props.viewId` 绑定任一视图，主/内联共用，内部无特判）。每个画布 = 一个 `v-stage`：网格层（最底，仅主视图）→ 连线层（独立 layer，保证节点恒在上）→ 节点层（`WhiteboardNode`/`InlineViewFrame` + Transformer + 框选矩形）。节点文本/连线的内联编辑用 DOM 覆盖层（textarea）实现；每个展开的内联视图是一个独立 `CanvasStage`，渲染在 `InlineViewCanvas` 的 DOM `<div>` 覆盖层上（z-index:10，物理恒浮在 Stage 之上）。

## 相关文件

| 文件 | 职责 |

| `WhiteboardCanvas.vue` | 主视图入口薄封装：`<CanvasStage view-id="main" :allow-expand show-overview-map>` |
| `CanvasStage.vue` | 通用画布：Stage 渲染、事件分流（拖动/框选/连线创建/平移）、全局 Transformer、文本编辑器生命周期 |
| `WhiteboardNode.vue` | 节点：v-group + v-rect + 多片段 v-text（`@引用` 分段高亮）、双击编辑、引用跳转、标签胶囊 |

## 关键类型与函数

- **`CanvasStage` 事件分流**（`handleStageMouseDown`）：Shift 按住 → 连线创建；PanMode → 平移；命中节点 → `nodeDrag`；空白 → `marquee` 框选。mousemove/mouseup 同理按状态分发到 `useNodeDragging`/`useMarqueeSelection`/`useConnectionCreation`。
- **全局 Transformer**（节点层单实例，替代每节点独立 Transformer）：`attachTransformer()` 按 `view.selectedNodeIds` 从 `nodeInstances` Map 收集中选节点的 Konva.Rect 附着；`onTransformEnd` 把 `scale` 烘焙回 `width/height`（Konva resize 只改 scale，需固化），内联视图节点走 `commitNodeResize` + 同步 `inlineViews` 尺寸，普通节点走 `resizeNode` + `commitNodeResize`。`boundBoxFunc` 禁翻转（宽/高低于 MIN 回退）。
- **节点引用识别**：节点外层 `v-group` 的 `name` 设为节点 ID（`WhiteboardNode`/`InlineViewFrame` 均如此），事件命中后用该 name 解析 nodeId。

## 内联视图（DOM 覆盖层渲染）

- 每个内联视图 = 一个独立 `CanvasStage`（`viewId` 非 `'main'`），渲染在 `InlineViewCanvas` 的 `<div>` 覆盖层内；覆盖层只覆盖矩形内容区（`INLINE_VIEW_TITLE_HEIGHT` 标题栏下方），标题栏保留在宿主 Stage（`InlineViewFrame`）。仅 1 层嵌套，内联视图不再渲染小地图。
- **坐标换算**：外层容器 style = 世界坐标 × 宿主 `stageScale` + 宿主 offset（left/top），top 再偏 `INLINE_VIEW_TITLE_HEIGHT`；内嵌 Stage 为固定世界尺寸，缩放由内层 `transform:scale(hostStageScale)` + `origin:top left` 承担。Konva 的 `setPointersPositions` 会按缩放后 getBoundingClientRect 与固定 clientWidth 的比值归一化指针坐标，故 transform 不影响坐标正确性。
- **展开/收起是视图操作**（右键菜单，仅主视图），不入 undo；`project.switchView(id)` = 存快照 → 销毁全部内联实例 → 改 `viewedNodeId` → 恢复快照，任意时刻仅一套内联实例存活。
- **视图切换统一经 `ensureViewSynced`**：`switchView` 与导航历史前进/后退（`navigateBack/navigateForward`）共用私有 `ensureViewSynced(id, recordHistory)`，切换前先考虑有无标签恰好展示该视图——活动标签已观察则直接返回；其它标签观察则 `switchToTab` 激活该标签；否则更新活动标签 `viewedNodeId` 后 `doSwitch`。这样主视图始终与当前活动标签的 `viewedNodeId` 同步。
- **导航历史（`stores/navigation.ts`，定长 10 条）**：`switchView/switchToTab` 等切换在 `doSwitch` 时记录当前节点（`recordHistory=true`）；`navigateBack/Forward` 从历史取目标（跳过已删除节点）并传 `recordHistory=false`，避免返回/前进把自己再入栈，同时经 `ensureViewSynced` 同步标签。新建/打开项目时清空并以 ROOT 为基准起点。触发方式：`navBack`/`navForward` 快捷键（默认 `alt+left`/`alt+right`，见 `自定义快捷键.md`）与鼠标侧边键（XButton1/XButton2，固定）。

## 实现细节与踩坑点

- **Konva 事件冒泡**：Stage/层的 `@click`/`@dblclick` 必须过滤 `e.target !== e.currentTarget`，否则空节点点击会重复触发。
- **文本编辑器竞态**：`saved` 守卫 + `onBlur` 用 `setTimeout(0)` 延迟，保证 Enter 的 `save()` 先置 `saved`，防 blur 二次触发；补全下拉打开时不保存（mousedown.prevent 兜底）。
- **vue-konva v3 ref**：`ref<VueKonvaRef<Konva.Rect> | null>`，用 `rectRef.value?.getNode()` 取底层 Konva 实例；`nodeInstances` 用组件暴露的 `getRectNode()/getGroupNode()` 收集。
- **层级保持**：选中节点 + 内联视图宿主节点要 `moveToTop()`（头次 + 列表/内联视图长度变化时，见 `liftInlineViewsToTop`），与内联覆盖层 DOM 层级一致，避免「能遮标题栏、遮不了画布」的视觉割裂。
- **三个 composable**（`useNodeDragging`/`useMarqueeSelection`/`useConnectionCreation`）须注册 window mouseup/click 兜底（内联或覆盖层可能阻断 stage 事件）。
- **主视图容器尺寸**：`useStageSize` 全局共享真实容器尺寸（侧边栏挤压），主视图 `registerStageContainer` 注册，内联视图经 `props.width/height` 传容器尺寸。
