# 自定义快捷键

在设置面板的「快捷键」分类中，允许用户自定义部分快捷键的绑定，并配置「序号修饰键」。

## 设计概要

- **字符串即等价判定**：所有快捷键表示为规范化 chord 字符串（见 `utils/shortcuts.ts`）。
  修饰键按固定顺序 `mod > alt > shift` 拼接，`mod` 等价于 Ctrl 或 Meta(Cmd)。
  例：`a`、`mod+s`、`mod+shift+z`、`alt+1`、`tab`、`delete`。
- **单一运行时 Map**：`useKeyboardShortcuts` 把所有快捷键（可改 + 锁定）压成
  `Map<chord, { id, scope, run }>`。keydown 时 `toChordString(e)` 直接 O(1) 查表，
  结构上保证「一个按键至多命中一个动作」，不可能双触发。
- **scope 决定触发时机**：`'always'`（保存/打开/新建/搜索）在输入框/编辑守卫之前执行，
  即便正在编辑也能用；`'canvas'`（其余）在守卫之后执行。
- **冲突检测**：设置时 `assign(id, chord)` 校验候选键是否被锁定键或其它自定义动作占用，
  冲突则拒绝并返回冲突方（同样的「拒绝」策略，复用于节点引用重名）。

## 可自定义的动作

| id | 操作 | 默认绑定 | scope |
|---|---|---|---|
| `save` | 保存项目 | `mod+s` | always |
| `open` | 打开项目 | `mod+o` | always |
| `new` | 新建项目 | `mod+n` | always |
| `search` | 打开搜索面板 | `mod+f` | always |
| `group` | 组合选中节点 | `mod+g` | canvas |
| `enterChild` | 进入子视图 | `a` | canvas |
| `enterParent` | 进入父视图 | `q` | canvas |
| `toggleInline` | 展开 / 收起内联视图 | `tab` | canvas |
| `fitInline` | 内联视图自适应 | `r` | canvas |
| `deleteSelected` | 删除所选（字母 `d`） | `d` | canvas |

> 说明：删除目前有两个触发键——`Delete`/`Backspace`（固定，见下）与字母 `d`。
> `d` 已归入可自定义动作（默认 `d`），可被重绑或改给其它命令。
> AI 生成（`i`）/ 清除（`c`）已迁为 ai 插件的插件快捷键动作（`ai:generate` / `ai:clear`），
> 不在本表内，改键随插件设置栏目（覆盖持久化于插件配置文件）。

## 锁定的快捷键（不可自定义）

- 撤销 / 重做：`mod+z`、`mod+shift+z`、`mod+y`
- 对象剪贴板：`mod+c` / `mod+x` / `mod+v`
- 删除：`delete`（Del 键）、`backspace`（退格，固定）
- 取消选中：`escape`
- 数字序号 `1-9`（应用预设 / 打标签）

上述 chord（`RESERVED_CHORDS`）不可被自定义动作占用；用户设置时命中即拒绝。

## 序号修饰键

- 按住「序号修饰键」再按数字 `1-9`，对选中节点批量打/删标签；直接按数字则应用可见预设。
- 默认修饰键为 `t`，可在设置面板中改为其他**单个普通键**（不可为数字 `1-9`，不可为组合键）。
- 独立于动作注册表存于 `shortcutsStore.seqModKey`。

## 文件结构

- `types/shortcuts.ts`：`ShortcutScope`、`ShortcutChord`。
- `utils/shortcuts.ts`（纯函数，可单测）：`normalizeKey`、`toChordString`、`isValidChord`、
  `parseChord`、`formatChord`、`isModifierOnly`。
- `constants/shortcuts.ts`：`CUSTOM_SHORTCUTS`（动作元数据）、`RESERVED_CHORDS`、`DEFAULT_SEQ_MOD_KEY`。
- `stores/shortcuts.ts`：`overrides` / `seqModKey`（localStorage 持久化 + 自愈）、
  `bindings`（覆盖优先回退默认）、`assign`（冲突校验）、`setSeqModKey`、`reset` / `resetAll`。
- `composables/useKeyboardShortcuts.ts`：由 `runtimeMap`（computed）统一装配锁定 + 可改动作，
  按 scope 在守卫前后执行；`seqHeld` 追踪序号修饰键按住态。

## 持久化与自愈

- `localStorage('aidea-shortcuts')`：用户覆盖绑定，仅存被改动项；
  加载时忽略未知 id / 非法值，并清理相互冲突的重复键（保留先到者）。
- `localStorage('aidea-shortcuts-seqmod')`：序号修饰键；非法则回退默认 `t`。

## 设置界面

`ShortcutsSection.vue`：每个可自定义动作一行（标签 + 当前键，点击进入「按键录制」+ 单行恢复默认）。
「按键录制」用 window 捕获阶段监听并 `stopImmediatePropagation`，避免录制时误触全局快捷键。
冲突以行内错误提示。底部「恢复全部默认」带确认框。另含「序号修饰键」行。

## 新增自定义动作

在 `constants/shortcuts.ts` 的 `CUSTOM_SHORTCUTS` 追加一项，并在
`useKeyboardShortcuts.ts` 的 `customRuns` 补充对应 run 实现即可。
若其 scope 为 `always`，会自动在守卫之前触发。

## 插件注册的动作（运行时注册）

插件可经 `api.shortcuts.registerAction({ id, label, scope, defaultChord?, run })` 注册自定义动作，
进同一套体系（设置面板可录制改键、冲突检测、bindings 合并、runtimeMap 分发）：

- 登记在 `stores/uiRegistry.ts` 的 `shortcutActions` 表，key = `${pluginId}:${id}`（插件命名空间隔离）；
  插件禁用（重启生效）后动作消失，setup 失败经 `removePlugin` 回滚。
- `label` 为成品字符串（插件不走主 i18n）；`scope` 语义与内置一致（`always`/`canvas`）。
- `defaultChord` 可选：给出则作为默认绑定（校验非法/保留键/与全部动作当前生效绑定冲突后登记），
  不给出则默认无绑定（设置面板显示空，可录制）。
- `validate` 自愈对含 `:` 的插件命名空间覆盖跳过清理：插件禁用期间覆盖保留，重装后恢复。
- 冲突返回 `{ ok, conflict: 'id' | 'chord' }`，供插件探测；`ShortcutsSection` 的动作行 =
  内置 `CUSTOM_SHORTCUTS` 在前 + 插件登记序在后。
