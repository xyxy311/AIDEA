# 预设管理

左侧活动栏面板（id `'presets'`，图标 `ColorPaletteOutline`），集中管理节点预设与连线预设，并支持**分组**。节点与连线的分组完全独立，可分别增删改与筛选。

## 功能行为

- **类型切换**：顶部分段按钮在「节点预设 / 连线预设」间切换。两类数据与分组互不影响。
- **分组筛选（节点/连线各自独立）**：下拉框在「全部 / 未分组 / 各分组（含内置）」间切换，列表即时过滤。节点与连线各自记住并独立展示自己的分组筛选状态。
- **序号徽标**：列表项前显示 1-9 小徽标，提示对应快捷键数字；仅对可见列表前 9 项显示。
- **列表项**：拖拽手柄 + 序号徽标 + 预览（节点=色块，背景由边框色派生；连线=迷你线段小样，含线型/粗细/箭头）+ 名称 + 分组标签 + 编辑（✎）+ 删除（✕，`NPopconfirm` 确认）。
- **应用预设**：点击列表项，将预设应用到当前选中对象（节点 `updateSelectedNodesStyle({borderColor})`；连线 `updateSelectedConnectionsStyle({...完整样式})`）。无选中时 `message.info` 提示。
- **新建 / 保存当前为预设**：按钮在分组下拉框下方。新建/编辑用弹层表单（节点：名称+边框色；连线：名称+线型+粗细+颜色+箭头）+ 分组选择。**默认选中当前分组**（`currentXxxGroupId`），并提供「新建分组」按钮：当场为当前类型建分组并自动设为选中分组。保存当前为预设会读取当前选中项样式预填，无选中时按钮禁用。
- **分组管理弹窗**：列出当前类型的分组，支持新增/改名/删除（删除用 `NPopconfirm`）。内置保留分组（`builtin: true`，名称「内置」）不可删除/改名，按钮禁用并显示提示。
- **浮动编辑器同步**：浮动编辑器预设横条（`FloatingColorStrip`）展示与面板一致的**当前分组可见列表**（`visibleNodePresets`/`visibleConnectionPresets`），面板切换分组后浮动条同步。

## 架构

```
PresetManagerPanel.vue            # 左侧活动栏面板（注册于 constants/panels.ts）
    └─ 消费应用层纯消费 stores/presets.ts（不改写数据层）
```

组件内部结构：面板标题栏 → 类型 Tab → 分组下拉+管理按钮 → 新建/保存按钮 → 可见预设列表（`NScrollbar`）→ 三个 `NModal`（预设表单 / 分组管理 / 分组名称输入）。

### store API（presets.ts）

| 能力 | API |
| --- | --- |
| 分组列表（节点/连线独立） | `nodeGroups` / `connectionGroups`（`{id,name,builtin}`） |
| 分组 CRUD（按类型） | `addGroup(type,name)` / `updateGroup(type,id,name)` / `deleteGroup(type,id)` |
| 分组查询 | `getGroup(type,id)` / `groupName(type,id)`（id 可 null） |
| 分组筛选状态（独立） | `nodeGroupFilter` / `connectionGroupFilter`、`setNodeGroupFilter(f)` / `setConnectionGroupFilter(f)` |
| 可见（筛选后）列表 | `visibleNodePresets` / `visibleConnectionPresets`（1-9 快捷键作用于此） |
| 新建预设默认分组 | `currentNodeGroupId` / `currentConnectionGroupId` |
| 可见列表内重排 | `reorderVisibleNodePresets(from,to)` / `reorderVisibleConnectionPresets(from,to)` |
| 预设 CRUD | `add/update/deleteNodePreset`、`add/update/deleteConnectionPreset` |

### 分组独立

节点与连线是**两套完全独立的分组**：各自的分组数组、分组 CRUD、局部撑持的筛选状态。在连线预设中新增分组不会让节点预设多一个分组；删除某个节点分组不会影响连线分组。预设项的 `groupId` 引用其所属类型的分组列表。

### 可见列表内重排

面板在筛选视图内拖拽排序时，调用 `reorderVisibleXxx(fromIndex, toIndex)`（索引是**可见列表**的索引）。store 内部经 `reorderVisible` 把排序结果合并回**全列表**，保持未显示项（其它分组/未分组）在原全列表中的相对位置不变。

### 持久化与自愈（无旧版兼容）

- 数据经 `useStorage` 写入 localStorage（`bb-preset-nodes` / `bb-preset-connections` / `bb-preset-node-groups` / `bb-preset-connection-groups` / 两个筛选 key）。
- 加载时 `validateStorages` 对每项做结构校验；JSON 解析失败或结构不符 → `localStorage.removeItem` 删除坏文件并回退默认值。
- `sanitizeFilters` 清理指向不存在分组的孤儿筛选值。
- `initDefaults` 确保「内置」保留分组存在，预设为空时用默认预设初始化并归入内置分组。

## 关键文件

| 文件 | 职责 |
| --- | --- |
| `stores/presets.ts` | 预设/分组数据、筛选、可见列表、重排、持久化与自愈（单一数据源） |
