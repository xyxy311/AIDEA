# 节点搜索功能

`SearchPanel` 是左侧活动栏面板（id `'search'`），用于在全局节点树中按文本搜索节点，可点击进入其子视图。

## 功能行为

- **搜索范围**：整个 `node.text`（含多行），大小写不敏感。
- **范围切换**：下拉框选择「整个项目」或「当前视图」。
  - **整个项目**（默认）：搜索全部节点。
  - **当前视图**：仅搜索当前视图（`project.currentNodeId`，主视图 viewedNodeId）的**直接子级**，即画布当前显示的节点。
- **排除根节点**：`parentId === null`（项目名）不参与搜索。
- **两行结果展示**：
  - 标题行（首行）；
  - 命中行片段（命中在**首行**时 `body = null`，避免两行重复展示同一段）。
- **超长省略**：单行超过 `maxChars`（默认 60）时，无命中截尾补 `…`；有命中则以命中点为中心取窗口，两侧补 `…`，保证命中高亮完整可见。
- **高亮**：命中片段用 `var(--color-primary-soft)` 淡底 + `var(--color-primary-pressed)` 文字。
- **点击导航**：单击结果行 → `project.switchView(nodeId)` 进入该节点子视图；当前节点对应行高亮 active。
- **快捷键**：`Ctrl/Cmd + F` 打开搜索面板并聚焦搜索输入框（编辑文本时也可触发）。

## 架构

搜索逻辑集中在**纯函数层** `src/utils/search.ts`，不依赖任何 store，便于单测与复用。组件只负责输入、渲染与导航。

```
SearchPanel.vue                    # 输入框 + 结果列表 + 高亮渲染 + switchView
    └─ calls ──> utils/search.ts   # 纯函数搜索与高亮切割
```

### utils/search.ts 关键函数

| 函数 | 作用 |
| --- | --- |
| `highlightLine(line, query)` | 把整行按命中切分为 `HighlightSegment[]`（`{text, match}`），保留原始大小写 |
| `buildDisplayLine(line, query, maxChars)` | 构建单行展示分段：超长时以命中为中心取窗口 + `…` |
| `buildSearchLines(text, query, maxChars)` | 组装两行：`{ title, body }`；命中在首行时 `body = null` |
| `searchNodes(nodes, query, options?)` | 全树搜索（排除根节点），返回 `SearchNodeResult[]`；`options.scope` 控制范围（`'project'` / `'view'`） |

### 搜索范围类型

```ts
type SearchScope = 'project' | 'view'

interface SearchOptions {
  scope?: SearchScope     // 搜索范围：'project' 全项目 / 'view' 当前视图
  viewedNodeId?: string   // scope='view' 时当前查看的节点 ID（取其直接子级）
  maxChars?: number       // 最长可显示字符数
}
```

`searchNodes` 内部对 `scope === 'view'` 的节点做 `node.parentId !== viewedNodeId` 过滤，仅保留当前视图直接子级。

### 高亮分段类型

```ts
interface HighlightSegment { text: string; match: boolean }
interface SearchNodeResult {
  nodeId: string
  title: HighlightSegment[]      // 标题行（首行）分段
  body: HighlightSegment[] | null // 命中行片段；命中在首行时为 null
}
```

## 面板注册

新增面板只需在 `constants/panels.ts` 注册，活动栏图标、面板容器、拖拽排序、展开/收起自动生效：

```ts
export type PanelId = 'nodeTree' | 'references' | 'search'

PANEL_REGISTRY.push({ id: 'search', titleKey: 'leftSidebar.search', icon: SearchOutline })
PANEL_COMPONENTS.search = SearchPanel
```

## 响应式

`SearchPanel` 内 `results` 为 `computed`，经 `searchNodes(Array.from(nodeStore.nodes.values()), query, { scope, viewedNodeId: project.currentNodeId })` 计算。`nodeStore.nodes` 是 `reactive(Map)`，文本修改 / 节点增删会自动触发重算；`scope` 或 `project.currentNodeId` 变化同样触发重算，无需手动刷新。

## 快捷键聚焦

`Ctrl/Cmd + F` 在 `useKeyboardShortcuts` 中处理：`layout.setActive('search')` 打开面板 + `requestSearchFocus()` 请求聚焦。聚焦信号为**待处理标志**（`pendingSearchFocus`，见 `composables/useSearchFocus.ts`）：

- 面板已打开：`watch(pendingSearchFocus)` 触发聚焦；
- 面板收起（未挂载，`LeftSidebar` 用 `v-if` 渲染）：`onMounted` 消费待处理标志并聚焦，保证按**一次** Ctrl+F 即进入聚焦搜索状态。

## 文案（i18n）

`src/locales/zh-CN.json` 的 `leftSidebar` 段：
- `search`：面板标题「搜索」
- `searchPlaceholder`：输入框占位「搜索节点…」
- `searchHint`：未输入提示「输入关键字搜索节点」
- `searchEmpty`：无结果提示「暂无匹配节点」
- `searchScopeProject`：范围下拉「整个项目」
- `searchScopeView`：范围下拉「当前视图」

## 测试

`src/__tests__/utils/search.test.ts` 覆盖：
- `highlightLine`：大小写不敏感、多段命中、空 query；
- `buildDisplayLine`：短行整行高亮、超长截尾省略、超长命中居中窗口且命中完整保留；
- `buildSearchLines`：命中首行 `body = null`、命中非首行 `body` 有命中；
- `searchNodes`：过滤、排除根节点、大小写、多行全文、空/空白 query、无匹配；
- `searchNodes`（范围）：`scope='view'` 只返回当前视图直接子级（三级树验证）、默认 `scope='project'` 全项目行为。
