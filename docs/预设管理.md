# 预设管理

左侧活动栏面板（id `'presets'`，图标 `ColorPaletteOutline`）集中管理**节点预设**与**连线预设**，且两组数据/分组**完全独立**。`stores/presets.ts` 是**单一数据源**：面板、右侧属性编辑器与浮动编辑器共用同一 store，增删改自动同步。节点与连线的分组、分组筛选状态各自独立（互不影响）；分组的 1-9 快捷键作用于**当前分组筛选下的可见列表**（`visibleNodePresets`/`visibleConnectionPresets` 的对应索引项），随筛选联动。

## 相关文件

| 文件 | 职责 |
| --- | --- |
| `stores/presets.ts` | 预设/分组数据、筛选、可见列表、重排、持久化自愈（单一数据源） |
| `components/panels/PresetManagerPanel.vue` | 预设管理面板：Tab/筛选/序号/拖拽/增删改/保存当前/分组管理 |
| `components/floating/FloatingColorStrip.vue` | 浮动编辑器预设横条，展示并渲染与面板一致的当前分组可见列表 |

| `components/common/DraggableSortList.vue` | 通用可拖拽排序列表（1-9 序号徽标），供面板复用 |

## 关键类型和函数

- **类型**：`NodePresetStyle`/`ConnectionPresetStyle`（预设项，含 `groupId`，`null`=未分组）、`PresetGroup`（`{id,name,builtin}`，内置分组 `builtin:true` 不可删/改名）、`PresetGroupFilter`（`'all'`/`'ungrouped'`/分组 id）。
- **分组 CRUD**（按类型独立）：`addGroup/updateGroup/deleteGroup(type, ...)`；查询 `getGroup/groupName`。
- **筛选状态**（独立）：`nodeGroupFilter`/`connectionGroupFilter` 及 `setNodeGroupFilter`/`setConnectionGroupFilter`。
- **可见列表**（筛选后，1-9 快捷键作用于此）：`visibleNodePresets`/`visibleConnectionPresets`。
- **新建预设默认分组**：`currentNodeGroupId`/`currentConnectionGroupId`（当前筛选为具体分组时归入，否则未分组）。
- **重排**：`reorderVisibleNodePresets`/`reorderVisibleConnectionPresets` 在可见列表内排序后**合回全列表**；全列表重排用 `reorderNodePresets`/`reorderConnectionPresets`（右侧/浮动编辑器用）。

## 模块内部组织关系与调用链

分组筛选（`nodeGroupFilter`/`connectionGroupFilter`）决定可见列表 `visibleNodePresets`/`visibleConnectionPresets`，面板与浮动条共用这一可见列表渲染，切换分组即同步。可见列表内拖拽排序调用 `reorderVisibleXxx(from,to)`，store 内经 `reorderVisible` 合并回全列表（保持未显示项相对位置不变）。新建预设默认归入当前分组（`currentNodeGroupId`）。

## 实现细节与踩坑点

- **持久化与自愈（无旧版兼容）**：数据经 `useStorage` 写入 localStorage。加载时 `validateStorages` 对每项做结构校验，JSON 解析失败或结构不符 → 删除坏文件并回退默认值；`sanitizeFilters` 清理指向不存在分组的孤儿筛选值；`initDefaults`（含 `ensureBuiltinGroup`）保证「内置」保留分组存在、预设为空时用默认预设初始化并归入内置分组。
- **分组完全独立**：节点与连线各有一套分组数组、分组 CRUD、筛选状态与 localStorage key，互不影响。
- **1-9 随筛选联动**：快捷键按 `visibleXxx` 的索引取值，筛选改变则快捷键对应项随之改变。
- **删除分组**：内置分组不可删；删除某类型的某分组时，该类型下该分组的预设转为未分组，若此刻正筛选该分组则筛选回落 `'all'`。
