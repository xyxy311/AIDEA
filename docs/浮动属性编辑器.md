# 浮动属性编辑器

Word 风格浮动属性编辑器：选中节点/连线时，在选中物旁自动弹出，专注高频样式操作。归属整个应用（不做视图判定），Teleport 到 body + `position:fixed` 渲染，避免被 `overflow:hidden` 裁切。

## 功能行为

- **显隐**：只要主视图全局选中（`selectedNodeIds.size > 0 || selectedConnectionIds.size > 0`）即弹出；节点与连线互斥（view store 已保证）。点击空白画布取消选中即隐藏。
- **选中节点**：自由改色（`NColorPicker`，hex + alpha）+ 节点预设横条（纯色圆点）。点击色块应用 `{ borderColor }` 到所有选中节点。
- **选中连线**：自由改色（hex，无 alpha）+ 连线预设横条（迷你线段小样：实线/虚线/点线 + 有向箭头）+ 线型 `NSelect` + 粗细 `NInputNumber(show-button)` + 有向 `NCheckbox`（**非 NSwitch**）。点击色块应用**完整预设样式**到所有选中连线。
- **预设统一**：与右侧边栏共用 `presetsStore`，`+` 添加、右键色块弹 `ContextMenu`（编辑/删除），增删改两边同步。
- **半透明**：鼠标不在面板上时 `.is-dimmed { opacity: 0.25 }`（`@mouseenter/@mouseleave` 切 `isHovered`），移入恢复不透明。
- **拖拽节点时隐藏**：拖拽移动节点期间面板以 `v-if` 隐藏，拖拽结束（节点仍选中）自动恢复。

## 架构

```
AppShell.vue                       # 单实例挂载 <FloatingPropertyEditor />
    └─ composables/useFloatingPropertyEditor.ts   # 显隐 + 锚点计算 + 拖动 offset
        └─ components/floating/
            FloatingPropertyEditor.vue   # 定位容器 + 拖动把手 + 节点/连线内容分发
            FloatingColorStrip.vue       # 水平预设横条（含右键菜单）
            FloatingPresetEditor.vue     # 添加/编辑预设紧凑弹层
```

### 定位与锚点

世界坐标 → 屏幕坐标：`screen = world * stageScale + stageOffset + view.containerEl.getBoundingClientRect()`（内联视图额外乘宿主缩放）。

- **渲染视图解析**：`resolveRenderView(parentId)` 先在 `mainView.inlineViews` 找 `nodeId === parentId` 的内联视图，否则用主视图 `'main'`。
- **节点锚点**：节点顶部居中偏上（`x + width/2, y`）。
- **连线锚点**：两端节点中心连线的中点。
- **最终定位**：`basePosition = anchor + offset`，组件内 `translate(-50%, -100%)` 居中置于锚点上方，再按视口 8px 边界夹取。

### 拖动（无位置记忆）

头部为拖拽把手，用 `pointerdown/move/up` + `setPointerCapture` 实现；`offset` ref 记录位移，最终位置 = 锚点 + offset。**无位置记忆**：`watch(selectionKey)` 选中项变化时 offset 归零，每次选中重新锚定，不持久化。

### 面板宽度固定

`.float-editor` 用固定 `width: 300px`（非内容撑开）。预设横条用 `NScrollbar x-scrollable` + `flex: 1; min-width: 0` 占满面板可用宽度并在面板内滚动；色块 `flex-shrink: 0`、内容行 `width: max-content`。避免预设增多时面板被撑宽、滚动条不可见。

### 全局拖拽信号

`useNodeDragging.ts` 导出模块级共享 `globalIsDraggingNode = ref(false)`：

- 拖拽激活（`processDragMove`）置 `true`；
- `cleanupDragState` 置 `false`（幂等，纯 click 未激活也安全）。

`useFloatingPropertyEditor` 的 `hasSelection` 并入 `&& !globalIsDraggingNode.value`，实现拖拽期间隐藏面板。选模块级 ref 而非独立 store，避免 import 环、零开销。

## 关键文件

| 文件 | 职责 |
| --- | --- |
| `composables/useFloatingPropertyEditor.ts` | 显隐、渲染视图解析、锚点屏幕坐标、拖动 offset（无记忆） |
| `components/floating/FloatingPropertyEditor.vue` | Teleport 定位容器、拖动把手、自由改色、节点/连线内容分发 |
| `components/floating/FloatingColorStrip.vue` | 水平预设横条（节点色点 / 连线小样）、`+` 添加、右键 ContextMenu |
| `components/floating/FloatingPresetEditor.vue` | 添加/编辑预设弹层（节点：名称+色；连线：+线型+粗细+箭头） |
