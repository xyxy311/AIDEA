# 基础组件

## 核心架构

`src/components/common/` 存放跨功能复用的通用组件，分为两类：

- **面板/外壳类**：提供统一外观与布局能力（`DockPanel`/`DockContainer`/`TopBarButton`/`TopBarZone`/`FloatingWindow`/`ModalShell`）。
- **数据/交互类**：纯展示与可复用交互（`DraggableSortList`/`NodeItem`/`ShortcutActionRow`/`WheelScroll`）。

约定：**外壳类负责标题/图标/关闭/拖拽/滚动等通用职责，内容组件保持纯内容**；新增面板/按钮的纵向排序列表一律优先复用 `DraggableSortList`。

## 关键组件用法

### DraggableSortList（可拖拽排序列表）

- 用途：封装 HTML5 拖拽排序（拖拽手柄、拖拽态、落点高亮）与 1-9 序号徽标，供各面板复用。
- 用法：`:items` 传列表数据（元素须含 `id`）；列表项内容经**默认作用域插槽** `#default="{ item }"` 传入，空态经 `#empty`。拖拽落点触发 `@reorder(from, to)`，面板据此调对应 store 的 reorder；整行点击触发 `@row-click="(item)=>..."`（可选）。`:show-shortcut-badge` 控制序号徽标显隐（默认 true）、`:shortcut-title` 设 hover 提示。
- 案例：`PresetManagerPanel`（开徽标）、`TagsPanel`（关徽标）。
- **复用约定**：面板纵向可拖拽排序列表一律复用该组件，只把「每行内容」封装进作用域插槽，不要重写拖拽逻辑/样式。行内操作按钮（编辑/删除/改色）须 `@click.stop` 与行点击隔离，避免误触发 `@row-click`。

### NodeItem（节点行展示）

- 用途：纯展示组件，用于「可引用节点面板」「搜索面板」统一展示节点行（标题 + 标签胶囊 + 路径 + 悬停提示）。不持有交互/数据适配。
- 用法：传 `:node`；标题经 `#title="{ node }"`、可选正文经 `#body="{ node }"` 插槽覆盖；`:show-path`/`:show-tags` 控制路径行与标签胶囊显隐。路径逻辑在 `utils/nodePath`（可单测）。

### WheelScroll（滚轮横向滚动）

- 用途：内容超出时可横向滚动、未超出时等宽排列无副作用；滚轮（含 shift+横向 delta）驱动 `scrollLeft`，纵向滚动被消费不带动页面。
- 用法：把内容放进 `<WheelScroll><slot/></WheelScroll>`，宽/高由外层 flex 布局接管，滚动条隐藏。
