# 节点搜索功能

## 核心架构

`SearchPanel`（左侧活动栏 id `search`）在全局节点树中按 `node.text` 搜索（大小写不敏感），核心逻辑集中在**纯函数层 `utils/search.ts`**，组件只做输入/渲染/导航。搜索结果 `results` 是 `computed`（`searchNodes(Array.from(nodeStore.nodes.values()), query, { scope, viewedNodeId: project.currentNodeId })`），随节点文本/增删及 scope、当前节点变化自动重算。搜索范围分「整个项目」（默认）/「当前视图」（scope='view' 仅取当前视图直接子级）。

```
SearchPanel.vue                # 输入/渲染/导航，computed results
    └─ calls ─> utils/search.ts # 纯函数：搜索 + 高亮切分，无 store 依赖，可单测
```

## 关键类型和函数

- 纯函数（`utils/search.ts`）：
  - `searchNodes(nodes, query, options?)`：全树搜索，排除根节点（`parentId===null`）、空 query 返回 `[]`；`options.scope` 控制范围、`scope='view'` 时用 `options.viewedNodeId` 过滤直接子级、`options.maxChars` 控超长截断（默认 60）。
  - `highlightLine(line, query)`：整行按命中切为 `HighlightSegment[]`，保留原始大小写。
  - `buildDisplayLine(line, query, maxChars)`：构建单行展示分段，超长以命中为中心取窗口两侧补 `…`，无命中截尾补 `…`。
  - `buildSearchLines(text, query, maxChars)`：组装两行 `{ title, body }`，命中在首行时 `body=null`。
- 类型：
  - `SearchScope = 'project' | 'view'`
  - `SearchOptions { scope?, viewedNodeId?, tagIds?, maxChars? }`
  - `HighlightSegment { text, match }`（match 标记命中片段，UI 用于高亮着色）
  - `SearchNodeResult { nodeId, title: HighlightSegment[], body: HighlightSegment[] | null }`

## 模块内部组织关系和调用链

- **重算链**：`results` 为 `computed`，依赖节点树（`nodeStore.nodes` 的 `reactive(Map)`）、`query`、`scope`、`project.currentNodeId` 任一变化即自动重算，无需手动刷新。
- **点击导航**：单击结果行 → `project.switchView(nodeId)` 进入该节点子视图，当前节点对应行 active 高亮。
- **快捷键聚焦**：`Ctrl/Cmd+F` 打开面板并 `requestSearchFocus()` 置 `pendingSearchFocus` 待处理标志；面板打开时 `watch` 消费聚焦，面板收起未挂载时靠 `onMounted`（`LeftSidebar` 用 `v-if`）消费，保证按一次 Ctrl+F 即进入聚焦状态。

## 实现细节和踩坑点

- **排除根节点**：`parentId === null`（项目名）不参与搜索。
- **两行结果**：`buildSearchLines` 命中在首行时 `body = null`，避免两行重复展示同一段。
- **超长省略/命中居中开窗**：`maxChars`（60）内整行高亮；超长时以命中点为中心取窗口保证命中完整可见，两侧补 `…`，无命中则截尾补 `…`。
- **scope='view' 直接子级**：仅保留 `node.parentId === viewedNodeId` 的节点，即画布当前显示的直接子级。
- 可同时按 `tagIds`（AND 语义）过滤；命中片段用 `var(--color-primary-soft)` 淡底 + `var(--color-primary-pressed)` 文字。面板注册、i18n key（`leftSidebar.search*`）、测试（`src/__tests__/utils/search.test.ts` 覆盖高亮/省略/两行/范围）见对应文件。
