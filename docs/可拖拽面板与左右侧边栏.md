# 可拖拽面板与左右侧边栏（dock）

## 核心架构

左侧是活动栏（`ActivityBar` 竖向图标条）+ 单面板区（`LeftSidebar`），右侧是 PS/Blender 式多面板 dock（`RightSidebar` 内 `DockContainer` 垂直堆叠）。**所有面板地位等价**：都能进左或右，只是布局层不同；面板本身是纯内容组件，统一由 `DockPanel` 外壳承载标题 / 图标 / 关闭 / 拖拽手柄 / 滚动。本系统核心是 **delta 排布模型**：uiRegistry 登记表回答「有哪些面板及默认侧」，localStorage 只存用户显式改动（顺序覆盖 / 跨侧移动 / 关闭 = `removed` / 尺寸），渲染目录 = `deriveDockLayout(登记表, delta)` 实时派生；「恢复默认布局」即清空 delta。

## 关键类型和函数

- **`constants/panels.ts`**：`PanelDef` = `{ id, titleKey, icon, component, defaultPlacement: 'left'|'right' }`（只描述面板，不绑布局）；`PANEL_CATALOG` 全量表（顺序即默认展示顺序），`PANEL_INDEX`（id→def）、`PANEL_COMPONENTS`（id→组件）为其派生导出。新增面板只在此登记即自动生效。
- **`utils/dock.ts`**（可单测）：
  - `parseDockDelta(raw, isKnown)`：读 localStorage 后的容错清洗（过滤非法 / 重复 / 未知键，尺寸仅留正数）。
  - `deriveDockLayout(defs, delta)`：归属按 rightOrder/leftOrder 命中优先，`removed` 排除，其余按 `defaultPlacement`；顺序 = 该侧用户顺序优先 + 登记顺序追加。
  - `reorderSeq(seq, from, to)`：序列内换位（越界钳制），dock 与顶栏共用。
  - 拖拽协议：`PANEL_DRAG_MIME = 'aidea-panel'`，`writePanelDrag(e, { panelId, from })`，`readPanelDrag(e)`（解析失败返回 `null`）。
- **`stores/layout.ts`**：派生目录 `leftPanels` / `rightPanels` / `unplacedPanels`（渲染参考）、比例 `rightSizes`；动作 `moveToLeft` / `moveToRight` / `reorderRight` / `setRightSize` / `removePanel` / `resetDock` / `collapse` / `expand`，激活 `togglePanel` / `activePanelId` / `lastPanelId`。

## 模块内部组织关系和调用链

- **登记 → 派生 → 渲染**：组件在 uiRegistry 登记（内置 seed，插件经适配层注册 `plugin:id` key）；layout 读 localStorage 进 delta → `deriveDockLayout` 实时派生出 `leftPanels` / `rightPanels` / `unplacedPanels`，ActivityBar / LeftSidebar / DockContainer 按目录渲染，新增面板 / 插件注册自动按默认侧出现。
- **同容器换位**：左侧活动栏拖拽 → `layout.reorder(from, to)`；右侧 header 拖到另一面板位 → `layout.reorderRight(from, to)`。
- **跨侧移动**：右侧面板拖到活动栏容器 → `readPanelDrag` 为 `from:'right'` 时 `moveToLeft(id)`（末尾追加并按需激活）；活动栏图标 / 左侧面板 handle 拖到右侧 dock → `moveToRight(id, toIndex)`（移走当前激活则收起左侧）。
- **分隔条 resize**：pointer events 上下拖，保持相邻两块 flex 和不变按 delta 分配 → `setRightSize`。
- **关闭语义**：左侧单面板区 = `collapse()`（仅收起，保留活动栏图标，`expand()` 经 `lastPanelId` 恢复）；右侧 dock = `removePanel(id)`（移除回 `removed`，「+」浮层 `moveToLeft` 加回）。
- **插件发现集**：`setDiscoveredPluginIds` 回填后重清洗 delta，禁用→启用不丢布局、彻底移除的插件不滞留。

## 实现细节和踩坑点

- **HTML5 drag + `suppressClick`**：`dragstart` 置 `suppressClick=true`，`dragend` 用 `setTimeout(0)` 复位，抑制拖拽后紧随的 click 误切换面板。
- **`DockPanel` 为唯一外壳（面板纯化）**：`panels/` 下面板为纯内容组件，**不携带** header / title / hideHeader；标题 / 图标 / 关闭 / 手柄 / 滚动全由外层提供，面板内操作按钮仍自留。
- **`removed` 关闭语义防重启回弹**：关闭 = 写入 `removed` delta 而非从登记删除，故刷新后仍不再出现；恢复默认（清空 delta）后按 `defaultPlacement` 回位。
- 持久化键：`aidea-dock-left` / `aidea-dock-right` / `aidea-dock-sizes` / `aidea-dock-removed`（顶栏另存 `aidea-top-*`）；UI 文本一律经 `t()`。
