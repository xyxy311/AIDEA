# 主题与配色

## 核心架构

themeStore（`stores/theme.ts`）是**单一数据源**，同时驱动三处：Naive UI（`scheme.theme` + `naiveOverrides`）、CSS 变量（`watchEffect` 注入 `:root` 的 `--color-*`）、Konva 画布（`themeStore.scheme.canvas.*`）。配色在 `config/colorSchemes.ts`：将「明暗模式」与「主色调」解耦为两个正交维度，`combineScheme(mode, accent)` 合成完整 `ColorScheme`。

**两类颜色严格区分**：

- **UI chrome 色（随主题）**：画布背景、Transformer 框、框选矩形、连线高亮、网格/活动网格。定义于 `ColorScheme.canvas`，经 `themeStore.scheme.canvas.*` 响应式绑定。
- **节点/连线数据色（不随主题）**：`DEFAULT_NODE_STYLE`、`PRESET_STYLES`、`DEFAULT_*_PRESETS`、`CONNECTION_STROKE_COLOR`、`PLACEHOLDER_TEXT_COLOR`，存于 `constants/index.ts`。

> 新增 UI chrome 色加 `config/colorSchemes`；新增数据色加 `constants`。

## 关键结构与函数

- **`colorSchemes.ts`**：`ModeScheme`（light/dark，中性色 + 画布中性色 background/nodeTextColor）、`AccentScheme`（每主色含 light/dark 两个 `AccentVariant`：naiveOverrides + 主色 CSS 变量 + 主色相关画布色）。`combineScheme(mode, accent)` 返回 `ColorScheme { id, theme, naiveOverrides, cssVars, canvas }`，`id` 形如 `emerald-light`。
- **themeStore**：`mode`（`useColorMode`，localStorage `aidea-theme`，仅 light/dark，默认浅色）、`accentId`（`aidea-accent`，默认 emerald）、`locale`（`aidea-locale`）、`scheme`（computed）`schemeId`、`toggle`/`setMode`/`setAccent`/`setLocale`。
- **响应式绑定**：`scheme` 是 computed，在模板 / computed 内用 `themeStore.scheme.canvas.*` 即响应式跟随主题切换。

## 实现细节与约定

- `<style scoped>` **禁止硬编码十六进制**，必须用 `var(--color-*)`。
- 文本经 `t()`；自定义组件色值用 `var(--color-*)`；Konva chrome 色读 `themeStore.scheme.canvas.*`。
- **主题响应式陷阱**：`scheme.canvas.*` 色值必须在响应式上下文（computed/template）使用，不能赋给普通 const config，否则不随主题更新。
