# 插件系统 —— 已实现部分概览

> 简明清单：涉及文件位置 + 一句话职责。详见《插件系统设计.md》的设计细节。

## 结构总览

```
src/plugin/
  adapter.ts      # ★稳定壳：PluginAdapter / PluginContext / AideaPlugin 契约 + createPluginAdapter()（插件唯一入口）
  api/            # 分类应用 api（类型从实现派生，不手写接口）
  source.ts       # PluginSource（加载方式接口）+ StaticPluginSource（import.meta.glob 编译期收集）
  context.ts      # createPluginContext：组装上下文 + 管理 onDispose 清理钩子
  manager.ts      # PluginManager：生命周期（装载/启停/错误隔离/SDK 校验）
src/stores/plugin.ts      # pinia 运行时状态 + localStorage('aidea-plugins') 启停持久化
src/components/plugin/PluginManagerSection.vue  # 设置面板「插件」分区
plugins/hello/index.ts    # 示例插件，演示 api 查询/执行/私有命令
```

## 已实现能力

| 能力 | 说明 |
| --- | --- |
| 分类应用 api | `api.node / connection / tag / stylePreset / project / view`，写方法经 `useCommands` 自动入历史（可撤销） |
| 类型派生 | `XxxApi = ReturnType<typeof createXxxApi>`，签名唯一源头在实现处 |
| 装载 | 应用启动 `main.ts` 调 `usePluginStore().init()` → `PluginManager` 扫描装载 |
| 周期 | 识别 manifest / SDK 大版本校验 / setup·teardown / onDispose / 单插件错误隔离 |
| 启停 | 仅持久化 → 重启应用生效；`localStorage('aidea-plugins')` |
| 管理面板 | 设置栏新增「插件」分类，展示清单 + 启停开关 + 状态/错误 |
| 契约测试 | adapter 契约 + source 扫描 + manager 生命周期 + 组件挂载冒烟 |

## 关键设计点

- **命令不设表**：命令已并入 api，插件私有"多步命令"写成内部函数，无需注册。
- **可迁移性**：`PluginSource` 是唯一"加载方式"抽象，未来可在 `source.ts` 增加 `RuntimePluginSource` 替换，上层零改动。
- **错误隔离**：单插件 setup 抛错仅置该插件 `error` 态，不影响其他插件与应用。
