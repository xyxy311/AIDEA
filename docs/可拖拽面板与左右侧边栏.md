# 可拖拽面板与左右侧边栏（dock）

右侧边栏采用 **PS / Blender 式多面板 dock**：在固定宽度侧边栏内垂直堆叠多个面板，面板间有可上下拖拽的分隔条调整各自高度，面板本身可拖拽换位、可关闭；且面板可在**左侧活动栏**与**右侧 dock** 之间互通拖拽移动。

## 布局模型

```
┌─────────────── MenuBar ───────────────┐
├ ActivityBar ┬ LeftSidebar ┬ Toolbar ┬ RightSidebar ┤
│  (图标栏)    │ (单面板区)   ├ Canvas ─┤  (多面板 dock)│
└─────────────┴────────────┴──────────┴──────────────┘
```

- **左侧**：`ActivityBar`（48px 图标栏，始终可见）+ `LeftSidebar`（单面板区，激活 `activePanelId` 决定显示哪个面板）。保持 VSCode 风格不变。
- **右侧**：`RightSidebar`（可收起/展开、可调宽度）内部渲染 `DockContainer`，垂直堆叠多个可拖拽、可调高度的面板。

## 组件分层

| 组件 | 路径 | 职责 |
| --- | --- | --- |
| `DockPanel` | `components/common/DockPanel.vue` | 通用面板包裹组件：统一 header（拖拽手柄 `⋮⋮` + 标题 + 关闭按钮），内容走默认插槽，滚动用 `NScrollbar x-scrollable` |
| `DockContainer` | `components/common/DockContainer.vue` | 垂直堆叠 + 分隔条 resize + 换位 reorder + 跨容器 drop zone + 空态 |
| `RightSidebar` | `components/panels/RightSidebar.vue` | 右侧外壳（收起/宽度），内容渲染 `DockContainer` |
| `PropertyPanel` | `components/panels/PropertyPanel.vue` | 属性编辑器面板：按选中对象自动切换节点/连线属性编辑器 |

## 数据模型（layout store + utils/dock.ts）

面板归属用「左侧 ∪ 右侧 ∪ 未放置」三态：

```
leftPanels: PanelId[]                // 左侧活动栏顺序（= panels，单面板区）
rightPanels: PanelId[]               // 右侧 dock 顺序
rightSizes: Record<PanelId, number>  // 右侧各面板高度比例（flex-grow）
```

**约束**：一个面板同一时刻只能归属一侧。`utils/dock.ts` 提供纯函数做状态转换（`moveToLeftCore`/`moveToRightCore`/`reorderRightCore`/`setRightSizeCore`/`removePanelCore`/`normalizeDockState`/`defaultDockState`），可单测；`layout store` 只做薄封装 + 持久化。

**默认布局**：`leftPanels = PANEL_REGISTRY`（五大左侧面板），`rightPanels = ['property']`（属性编辑器常驻右侧）。

**持久化**：`useStorage` 写入 localStorage（`aidea-dock-left` / `aidea-dock-right` / `aidea-dock-sizes`），加载时 `normalizeDockState` 清理脏数据（无效/重复 id、保证互斥、补齐尺寸）。设置面板「恢复默认布局」调用 `layout.resetDock()`：删除三个 key 并重置默认值。

## 统一拖拽协议（全项目一致）

所有面板拖拽用 HTML5 drag，`dataTransfer` 携带跨容器移动信息：

```ts
const IDS = 'aidea-panel'
e.dataTransfer.setData(IDS, JSON.stringify({ panelId, from: 'left' | 'right' }))
```

读取端 `getData(IDS)` 后 `JSON.parse`，需容错 null。

## 交互行为

- **同容器换位**：右侧面板 header 拖拽到另一面板位置 → `layout.reorderRight(from, to)`。
- **跨容器移动**：
  - 右侧面板拖到左侧活动栏 → `layout.moveToLeft(panelId)`（加入左侧末尾并激活）。
  - 活动栏图标拖到右侧 dock → `layout.moveToRight(panelId, toIndex)`（从左侧移除，若为当前激活则收起左侧）。
- **分隔条 resize**：pointer events，按住面板间分隔条上下拖，保持相邻两块 flex 之和不变按 delta 分配，`layout.setRightSize`。分隔条下移 → 上方面板增大。
- **关闭面板**：DockPanel header 关闭按钮 → `layout.removePanel(panelId)`（从两侧移除，回到「未放置」）。
- **添加未放置面板**：活动栏底部「+」弹出浮层列出未放置面板，点击 → `moveToLeft`。

## 面板复用

- 左侧面板（NodeTree/References/Search/Presets/Tags）支持 `hideHeader?: boolean` prop：作为 dock 面板时隐藏自带 `.panel-header`，避免与 DockPanel 的 header 双重标题。
- `property` 面板封装节点/连线属性编辑器，标题统一为「属性」（`rightSidebar.property`），不随选区切换。
- 属性编辑器中的**预设管理已移除**，统一由左侧「预设管理」面板与浮动编辑器承担。

## store API 速查

```
layout.panels           左侧活动栏顺序（ref）      layout.rightPanels    右侧顺序（ref）
layout.rightSizes       右侧高度比例（ref）        layout.rightEmpty     dock 是否为空
layout.moveToLeft(id)   右侧 → 左侧               layout.moveToRight(id, idx)  左侧 → 右侧
layout.reorderRight(a,b) 右侧内换位               layout.setRightSize(id,flex) 设高度
layout.removePanel(id)  移除回未放置              layout.resetDock()           恢复默认
```
