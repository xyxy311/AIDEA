# 标签系统

给节点打标签，用于分类与检索。标签在节点右下角以胶囊显示，可在右侧属性面板为选中节点打标签，可在左侧标签管理面板统一增删改，并可在搜索中按标签过滤节点。

## 功能行为

- **节点显示**：打了标签的节点，在**右下角**渲染一排标签胶囊（圆角小药丸，底色 = 标签 `Tag.color`，文字用 WCAG 亮度的对比色）。右对齐、最多显示 4 个，超出以 `+N` 溢出胶囊示意；胶囊不响应事件，不拦截节点拖动/选中/双击/引用点击。
- **标签管理面板**（左侧活动栏，id `'tags'`，图标 `PricetagsOutline`）：顶部快速新建（名称输入独占一行 + 下方取色/添加按钮），列表每行「小色点 + 名称 + 改名/删除」。点击色点弹完整取色器改色；删除需确认，删除后自动移除所有节点上的该标签关联。
- **右侧添加标签**（`NodePropertyEditor`）：外观区下方「标签」区，`NSelect multiple`（选项带色点前缀）绑定选中节点 `tagIds`；单选即该节点自身标签，**多选时显示所有选中节点的共同标签交集（可编辑）**，改动只增删共同标签、保留各节点自有其它标签（走命令层可撤销），无标签定义时提示。
- **按标签搜索**（`SearchPanel`）：scope 下拉、关键字输入下方新增标签多选 `NSelect`，与关键字按 **AND** 叠加过滤（节点须同时含全部所选标签）。
- **快捷键打标签**：`T + 1-9`（按住 t 时按数字）对选中节点批量添加/删除「标签列表」中对应序号标签（全含则移除、否则添加，各节点保留自有其它标签）；与纯数字 `1-9` 应用预设区分。

## 存储模型

- **标签定义**：项目级数据，存 `stores/tags.ts` 的 `tags: reactive(Map<tagId, Tag>)`，`Tag = { id, name, color }`，**随项目文件序列化**（不入 localStorage，区别于全局预设 presets）。
- **节点关联**：节点加内联字段 `tagIds: string[]`（引用标签定义 id），与 `connections` 嵌套在节点内的模式一致——删除/复制/组合/迁移子树时 `tagIds` 随节点自然迁移。
- **反向索引**：`nodeStore.tagIndex` 为 `computed` 派生（`tagId -> nodeId[]`，仿 `referenceIndex`），供标签管理面板与按标签搜索做反向查询。

### 撤销策略（重要）

- **标签定义 CRUD（新建/改名/改色/删除）不可撤销**：直接改 `tags` Map + `markDataDirty()`，不经命令层。
- **仅"节点打标签"可撤销**：`useCommands.updateNodesTagsPerNode(ids, tagIdsPerNode)` 走 `nodeChanges.modify` 的 `tagIds` 字段（coalesceKey `tags-${sortedKey}`），进历史栈；`tagIdsPerNode` 与 ids 等长、逐节点分别设置，支持多选时各节点保留自有其它标签（整体替换同一组标签的旧入口 `updateSelectedNodesTags` 委托给它）。
- 因此**无需新增 `tagChanges` 通道，不改 `history.ts`**。

### 悬空引用容错

"标签定义不可撤销 + 打标签可撤销"的固有张力：undo 跨"删除标签"边界时，历史会用旧的 `tagIds` 恢复出一个已删除标签的 id（悬空引用）。因此**所有消费 `tagIds` 的地方都必须用 `tagsStore.getTag(id)` 过滤 undefined**（渲染胶囊、属性面板下拉、搜索过滤）。文件持久化侧由 `parseProjectFile` 裁剪非存在 id 自愈。

## 架构

```
stores/tags.ts             # 项目级标签定义 store（tags Map + CRUD + replaceTags/clearTags）
stores/node.ts             # WhiteboardNode.tagIds 字段 + tagIndex + updateNodesTagsPerNode + stripTagFromAllNodes
composables/useCommands.ts # updateNodesTagsPerNode（按节点分别设置，可撤销，modify nodeChanges）+ updateSelectedNodesTags（同组整体替换）
composables/useActiveView.ts # updateSelectedNodesTagsPerNode 编排（作用于全部选中节点）
components/panels/TagsPanel.vue      # 左侧标签管理面板（id 'tags'）
components/panels/NodePropertyEditor.vue # 右侧「标签」区 NSelect multiple
components/canvas/WhiteboardNode.vue # 节点右下角标签胶囊渲染 + 文本布局预留
utils/search.ts + components/panels/SearchPanel.vue # 按标签过滤
```

### 关键实现点

- **文本预留**：`WhiteboardNode.layoutLines` 与 `nodeStore.fitNodeToText` 用同一公式 `reservedBottom = NODE_PADDING + TAG_CAPSULE_HEIGHT + TAG_CAPSULE_BOTTOM_GAP`（有标签时），确保多行文本不与底部胶囊重叠。`updateNodesTagsPerNode` 写入 `tagIds` 后调 `fitNodeToText(id)` 触发高度扩张。
- **胶囊布局**：`capsuleLayout` 右对齐、从右往左贪婪摆放，受 `TAG_CAPSULE_MAX` 与节点宽度双重约束；溢出计数 = 总标签数 − 实际放置数（含空间截断）。
- **色块避免 NColorPicker 撑满**：`TagsPanel` 列表行色块用 `#trigger` 插槽渲染 14px 纯色圆点（NColorPicker 根自带 `width:100%` 且是 renderless VBinder，直接内联会撑满 flex 行挤压名称）；顶部取色块用 `flex: 0 0 40px` 强制固定。
- **胶囊数据色**：`Tag.color` 是数据色（不随主题）；溢出胶囊与胶囊文字对比色逻辑随主题（chrome 色）。

### utils/search.ts 标签过滤

```ts
interface SearchOptions {
  scope?: SearchScope
  viewedNodeId?: string
  tagIds?: string[]   // 按标签过滤：节点须同时含全部所选标签（AND）；空数组/undefined 不过滤
  maxChars?: number
}
```

`searchNodes` 在 scope 过滤之后、关键字匹配之前插入 `tagIds.every((tid) => node.tagIds?.includes(tid))`；`node.tagIds?.` 容错缺字段。

## 序列化

- `ProjectFileData` / `ParsedProject` 含 `tags: Tag[]`；节点 `tagIds` 随节点对象序列化。
- `parseProjectFile`：校验 `tags` 数组（元素须 id/name/color 均 string）；节点 `tagIds` 缺失兜底 `[]`；把 `tagIds` 裁剪为仅存在于定义集合内的 id（自愈）。
- 打开路径 `loadProjectIntoApp` → `tagsStore.replaceTags(data.tags)`；新建路径 `clearTags()` 由 `loadProjectIntoApp` 的 `tags ?? []` 兜底。
- **版本保持 1 前向兼容**：`tags` / `tagIds` 均为可选字段，旧文件缺失时补 `[]`。
