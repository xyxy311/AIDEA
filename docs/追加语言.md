# 向应用追加一种界面语言（即插即用，无需改码/重启/重编译）

本应用的界面语言「把规范语言包放进特定目录即自动登记」。**开发商（含最终用户对自己发行的包）不需要改动任何源码，也不需要重新构建。**

## 语言包放哪里

| 运行形态 | 运行时 i18n 目录 |
|---------|-----------------|
| 开发环境（`npm run dev`） | `<仓库根>/i18n-runtime/` |
| 正式版（打包后） | `userData/i18n/` |

把语言包 `.json` 文件放进该目录即完成登记；删除文件即取消登记。

## 语言包格式

透传一个完整的英文包当模板：`i18n-runtime/en-US.json`（目录默认自带，也是功能测试夹具）。

顶部的 `@meta` 必须保留并改为目标语言：

```jsonc
{
  "@meta": { "id": "es-ES", "label": "Español", "naiveBase": "en-US" },
  "menuBar": { "file": "Archivo", ... }
}
```

| 字段 | 要求 |
|------|------|
| 文件名 | `<id>.json`，如 `es-ES.json` |
| `@meta.id` | 与文件名（去 `.json`）**完全一致**；仅 `字母/数字/_/-`（允许大写，如 `zh-CN`、`en-US`） |
| `@meta.label` | 语言自名（用该语言写自己的名字，不翻译、不走 `t()`），在下拉中展示 |
| `@meta.naiveBase` | naive-ui 组件文案兜底语言 id；缺省 `en-US`。naive 自带该语言时写它自己（`en-US`→`en-US`），否则写最接近的一个 |
| 正文 | 与 `zh-CN.json` 的 key **完全同构**（`parity.test.ts` 守护两边 key 对齐）；漏掉的 key 运行时自动回退中文 |

> naive-ui 已内置的 && 建议使用的 `naiveBase`：`zh-CN` / `zh-TW` / `en-US` / `en-GB` / `ja-JP` / `ko-KR` / `de-DE` / `fr-FR` / `es-AR` / `it-IT` / `pt-BR` / `ru-RU`。其他语言若 naive 无对应，写 `en-US`。列表见 `src/composables/naiveLocale.ts`。

## 即插即用行为（三态热更新）

| 操作 | 行为 |
|------|------|
| **新增**语言文件 | 自动登记，立即可在「设置 → 外观 → 语言」下拉中选中；无需重启 |
| **覆盖**语言文件 | 重新登记并替换该语言文案；若正用该语言，界面文案即时刷新 |
| **删除**语言文件 | 自动从下拉消失；若当前正用该语言，自动回退中文（安全网） |

## 校验与兜底

- 放在目录里的**非法包**（无 `@meta` / `@meta.id` 与文件名不符 / JSON 损坏 / 文件名 id 非法）会被**静默跳过**，不影响程序运行，也不进下拉。
- `zh-CN` 永远内置兜底：即使运行时语言全部失效，界面仍回退中文。

## 说明

- 每次界面语言切换由单个 store（`stores/i18n.ts`，available / bundles）与 `useT`/`App.vue` 响应式链驱动，语言是用户偏好，只持久化 `id`（localStorage `aidea-locale`）。
- 正式版安装包构建（electron-builder 阶段）需用 `extraResources` 把 `i18n-runtime/`（含 `en-US.json`）作为初始模板带到 `userData/i18n/`；用户新增文件写同一目录，即继续自动登记。
