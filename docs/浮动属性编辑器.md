# 浮动属性编辑器

## 核心架构

Word 风格浮动属性编辑器：选中节点/连线时在选中物旁自动弹出，专注高频样式操作。归属整个应用（不做视图判定），Teleport 到 body + `position:fixed` 渲染，避免被 `overflow:hidden` 裁切。显隐逻辑集中在 `composables/useFloatingPropertyEditor.ts`，模板在 `components/floating/FloatingPropertyEditor.vue`（AppShell 单实例挂载）。

## 相关文件

| 文件 | 职责 |
|---|---|
| composables/useFloatingPropertyEditor.ts | 显隐、渲染视图解析、锚点屏幕坐标、拖动 offset（无记忆） |
| components/floating/FloatingPropertyEditor.vue | Teleport 定位容器、拖动把手、自由改色、节点/连线内容分发 |
| components/floating/FloatingColorStrip.vue | 水平预设横条（节点色点/连线小样）、+ 添加、右键 ContextMenu |
| components/floating/FloatingPresetEditor.vue | 添加/编辑预设紧凑弹层 |
| components/layout/AppShell.vue | 单实例挂载点 |
| composables/useNodeDragging.ts | 导出模块级 `globalIsDraggingNode` 拖拽信号 |
| stores/presets.ts | 与右侧属性编辑器共用的预设数据源 |

## 关键类型和函数

- `resolveRenderView(parentId)`：先在主视图 inlineViews 找该 parentId 的内联视图，否则用主视图 'main'。
- 坐标换算：`screen = world * stageScale + stageOffset + view.containerEl.getBoundingClientRect()`（内联视图额外乘宿主缩放）。
- 锚点：节点=顶部居中偏上（`x+width/2, y`）；连线=两端节点中心连线中点。
- 最终定位：`basePosition = anchor + offset`，组件内 `translate(-50%,-100%)` 居中置于锚点上方，再按视口 8px 边界夹取。
- `globalIsDraggingNode = ref(false)`（模块级共享，选模块级 ref 而非独立 store，避免 import 环）。

## 模块内部组织关系和调用链

选中变化（selectionKey）→ 计算锚点+offset → Teleport 定位容器 → 节点/连线内容分发（共用 presetsStore 的预设横条）；拖动节点期间 `hasSelection && !globalIsDraggingNode` 隐藏面板。

## 实现细节和踩坑点

- 拖动用 pointerdown/move/up + `setPointerCapture`；`watch(selectionKey)` 时 offset 归零（无位置记忆，不持久化）。
- 固定 `width: 300px`（非内容撑开）；预设横条用 `NScrollbar x-scrollable + flex:1; min-width:0` 占满并在面板内滚动，色块 `flex-shrink:0`；避免预设增多撑宽面板。
- 半透明：`@mouseenter/@mouseleave` 切 isHovered，未悬停 `opacity:0.25`。
- 拖拽移动节点期间面板 v-if 隐藏，拖拽结束自动恢复。
