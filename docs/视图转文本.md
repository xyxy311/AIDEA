# 视图转文本

把「视图节点」按空间位置编排成格式化文本，供 AI / 其它给 AI 提供项目上下文的函数理解项目内容。

## 用途

- 视图 = 某节点（当前 `project.currentNodeId`）的直接子级，即画布上渲染的节点。
- 把二维布局降维成有结构的文本：纵向分「行」、行内按横向排序，帮助 AI 感知节点的空间关系。
- 作为 AI 上下文的**唯一来源**：`useAIWordPanel.directGenerate()` 在预览为空时调用 `buildViewText` 自动生成上下文预览。
- 提供「生成文本」与「复制」能力。

## 架构：策略模式 + 算法注册表

算法定义在 `src/utils/viewText.ts`，为「自带参数 schema + 构建函数」的自描述对象：

```ts
interface ViewTextAlgorithm {
  id: string
  labelKey: string                 // 算法显示名 i18n key
  params: ViewTextParamSchema[]    // 参数 schema（面板据此动态渲染控件）
  build(nodes, params): string
}
```

- 面板只读注册表 `VIEW_TEXT_ALGORITHMS`，动态渲染算法下拉与参数控件，调用统一调度器 `buildViewText`。
- **替换 / 新增算法**只需在注册表追加一个 `ViewTextAlgorithm` 对象，面板零改动（下拉选项、参数控件自动出现）。

## 当前算法：行聚类（rowCluster，方案A）

参数：

| schema key | 类型    | 默认    | 说明 |
|---|---|---|---|
| `tolerance`   | number  | `10`    | 纵向聚行容差（px），用于归并视觉对齐但有微小间隙的节点 |
| `includeCoords` | boolean | `false` | 行内每项是否带 `[x,y]` 前缀 |
| `separator`   | select  | `'\t'`  | 行内连接符（制表符 / 逗号 / 分号 / 竖线） |

流程：
1. 节点按 `y` 升序排序。
2. 贪心聚行：节点与已有行的纵向区间重叠（含 `tolerance` 容差）则并入该行并扩展区间，否则新建行。
3. 每行内按 `x` 升序排序，用 `separator` 拼接；行间用 `\n` 拼接。

保证每个节点恰好出现一次，无去重歧义、无步长魔法参数。

## 文件

- `src/utils/viewText.ts` — 纯函数 + 算法注册表 + 调度器（可单测，不依赖 store）
- `src/components/panels/ViewTextPanel.vue` — 面板（左侧活动栏，纯内容，无 header，固定参数控件）
- `src/constants/panels.ts` — 面板品类表登记（活动栏 / 容器 / 拖拽 / 收起自动生效）
- `src/locales/zh-CN.json` — UI 文案
- `src/__tests__/utils/viewText.test.ts` — 算法与调度器单测

## 布局补充逻辑

`normalizeDockState`（`src/utils/dock.ts`）在加载时会补充「新增的默认面板」：
旧版本用户 localStorage 保存的布局不含新面板时，按 `defaultPlacement` 自动补到对应侧，
保证新增面板只需在品类表登记即可对已有用户生效（无需手动通过「添加面板」加入）。
