# 多语言

## 核心架构

i18n 是轻量占位层，未用 vue-i18n。资源是 `src/locales/*.json`（当前 `zh-CN.json` / `en-US.json`，点路径 key + `{name}` 插值）。入口 `composables/useT.ts`：导出全局 `t(key, params?)`，未命中回退 key。核心是一个 `createT(bundles)` 工厂，宿主全局 `t` 与插件语言包共用同一实现——未来迁移 vue-i18n 只需改 `useT.ts` 内部。

## 关键函数

- **`createT(bundles)`** → 返回 `t(key, params?)`。`bundles` 为按语言 id 注册的文案表集合。产物回退链：`bundles[当前语言]` → `bundles['zh-CN']` → 返回 key 本身。
- **`getLocale()`**：读 `themeStore.locale`（`useStorage('aidea-locale')`，默认 `zh-CN`）；pinia 未就绪回退 `zh-CN`。
- **`resolveThemeStore()`**：惰性获取并缓存 themeStore，避免模块顶层 import 时序早于 `app.use(pinia)` 报错；活动 pinia 变化（测试间）失效重建。
- **响应式依赖**：`getLocale()` 经 store 代理读取 locale，在 **computed / 模板内**调用即建立响应式依赖，切语言热更新。

## 用法与约定

- **所有用户可见 UI 文本必须经 `t()`**，禁止硬编码中文；新增文本同步加 key。
- `{name}` 插值：`t('key', { name })`，占位符逐个替换。
- 插件文案不进宿主 locales：需要多语言的插件在 `plugins/<name>/locales/` 自备语言包，经 `adapter.api.i18n.createT()` 得到自己的 t（见 `插件开发手册.md` 4.10）。
- **响应式约定**：`t()` / `getLocale()` / `createT` 产物必须在模板或 computed 中调用（内部读 themeStore.locale 建立依赖），禁止把调用结果赋给模块级常量（会固化首次语言）。注册描述符除外（成品字符串，取注册当时语言快照）。
