# 顶部栏按钮注册与拖拽（LeftTopBar + RightTopBar）

原「菜单栏 MenuBar / 工具栏 Toolbar」更名为 **`LeftTopBar` / `RightTopBar`**，并将按钮改为**品类表注册 + 可拖拽排序/跨区放置**，设计上完全模仿左右侧边栏（activity bar / dock）的注册与拖拽机制。

## 组件分层

| 组件 | 路径 | 职责 |
| --- | --- | --- |
| `TopBarButton` | `components/common/TopBarButton.vue` | **唯一按钮外壳模板**：统一 tooltip / active（底部主色指示条）/ primary（主色填充）/ disabled / split-button（主图标 + 小三角下拉）；按钮只提供 `icon/title/disabled/active/variant/menu` 与 `@click` |
| `TopBarZone` | `components/common/TopBarZone.vue` | **通用容器**：按 `layout` store 某侧顺序渲染已注册按钮 + 同侧拖拽排序 + 跨区投放；`LeftTopBar`/`RightTopBar` 是固定 zone 的薄封装 |
| `LeftTopBar` | `components/layout/LeftTopBar.vue` | 左顶部条（`<TopBarZone zone="left" />`，原 MenuBar） |
| `RightTopBar` | `components/layout/RightTopBar.vue` | 右顶部条（`<TopBarZone zone="right" />` + 尾部节点计数，原 Toolbar） |

## 按钮品类表（constants/topbar.ts）

全量按钮品类表 `TOP_BAR_CATALOG`（单一数据源），**不区分左右**：

```ts
interface TopBarDef {
  id: TopBarId
  titleKey: string            // 标题 i18n key
  defaultZone: 'left'|'right' // 默认放置侧
  component: Component        // 按钮逻辑组件（视觉外壳由 TopBarButton 提供）
}
```

按钮逻辑组件位于 `components/topbar/`（OpenButton / SaveButton / UndoButton / RedoButton / SettingsButton / DebugButton / AIDisplayModeButton / GridButton / AddNodeButton）。

派生导出：`TOP_BAR_INDEX`（id→def）、`TOP_BAR_COMPONENTS`（id→组件）、`DEFAULT_LEFT_TOP` / `DEFAULT_RIGHT_TOP`（由 `defaultZone` 派生）。

**新增按钮**：只需在 `TOP_BAR_CATALOG` 登记 `id + titleKey + defaultZone + component`（并提供对应按钮组件），左/右顶部条、拖拽排序、跨区放置、默认布局全部自动生效。

## 数据模型（layout store + utils/topbar.ts）

```
leftTop: TopBarId[]   // 左顶部条顺序
rightTop: TopBarId[]  // 右顶部条顺序
```

`utils/topbar.ts` 提供纯函数（`reorderTopCore`/`moveTopZoneCore`/`normalizeTopBarState`/`defaultTopBarState`）与统一拖拽协议（`TOP_DRAG_MIME`/`writeTopBarDrag`/`readTopBarDrag`），可单测；`layout store` 只做薄封装 + 持久化。

**默认布局**：由品类表 `defaultZone` 派生，不硬编码。
**持久化**：`useStorage` 写入 `localStorage`（`aidea-top-left` / `aidea-top-right`），加载时 `normalizeTopBarState` 清理脏数据并补新增默认按钮。设置「恢复默认布局」调用 `layout.resetDock()`（内含 `resetTopBar`，一并复位顶部按钮条）。

## 交互行为

- **同侧换位**：拖动某按钮到同侧另一按钮位置 → `layout.reorderTop(zone, from, to)`。
- **跨区移动**：拖动按钮到另一侧顶部条 → `layout.moveTopZone(buttonId, toZone)`（源侧移除 + 目标侧末尾追加）。`dataTransfer` 携带 `{buttonId, zone}`（MIME `aidea-topbar`）。
- **拖拽抑制误触**：`dragstart` 置 `suppressClick`、`dragend` 用 `setTimeout(0)` 复位；容器以 `@click.capture` 捕获吞掉拖拽后紧随的 click，避免误触按钮动作。

## store API 速查

```
layout.leftTop   左顶部条顺序（ref）       layout.rightTop  右顶部条顺序（ref）
layout.topOrder(zone)                    layout.reorderTop(zone, from, to)
layout.moveTopZone(id, toZone)           layout.resetTopBar()
```
