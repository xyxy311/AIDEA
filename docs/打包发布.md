# AIDEA 打包与发布

> 面向发版/运维：构建产物、electron-builder 配置、首跑种子、安装后数据存放，以及给已安装版本添加语言/插件的方法。

## 1. 构建流程

| 命令 | 说明 |
| --- | --- |
| `npm run dev` | Electron + vite 开发（内置 ai 插件每次先重打） |
| `npm run build` | 生产构建：`vue-tsc` 类型检查 → `vite build`（renderer → `dist/`）→ build-electron（vendor → `dist/vendor/`、main/preload → `dist-electron/`、AI 插件 → `plugins/ai/plugin.js`） |
| `npm run dist` / `npm run dist:win` | 先 `npm run build`，再 `electron-builder` 打 **Windows NSIS 安装包** |
| 所有产物输出到 | `release/`（`release/AIDEA Setup <版本>.exe` 安装包、`release/win-unpacked/` 免安装目录） |

## 2. electron-builder 配置（`package.json` 的 `build` 字段）

- `appId`: `com.xyxy.aideawhiteboard`；`productName`: `AIDEA`；`author`: `xyxy`
- `files` 只收 `dist/**` + `dist-electron/**` + `package.json`：`main.cjs`/`preload.cjs` 已由 esbuild **bundle**（`external` 仅 `electron`），`package.json` 也把全部运行时依赖放在 `devDependencies`（构建期已打进产物），因此 **asar 不携带 node_modules**，安装包更小。
- `extraResources`（首跑种子）：把打包出的 `plugins/ai/plugin.js` 与 `i18n-runtime/*.json` 放进安装包 `resources/seed/`。
- `win.target`: `nsis`；`oneClick: false` + `allowToChangeInstallationDirectory`（向导安装）；图标 `build/icon.png`（由 `icon/icon256.png` 复制，electron-builder 自动生成 exe/安装包图标）。

> 签名：`win.sign` 未配置证书时 electron-builder 跳过签名；正式对公发版需补代码签名证书。

## 3. 首跑种子（`electron/main/seedData.ts`）

生产安装后首次启动，`app.whenReady` 在注册协议/建窗前先把 `resources/seed/` 复制进 `userData`：

- `seed/plugins` → `userData/plugins`：**覆盖式**（内置固定 ai 插件，随版本更新）
- `seed/i18n` → `userData/i18n`：**只补缺失文件**（不覆盖用户已新增/改动过的语言包）

这样首次运行即有 AI 插件与默认语言模板（`en-US`）；`zh-CN` 编译期内置，始终兜底。

## 4. 安装后数据存放位置

`main` 进程 `app.setName('AIDEA')` 固定 `userData`。Windows 上即：

```
%APPDATA%\AIDEA\
```

| 数据 | 位置 | 说明 |
| --- | --- | --- |
| 全部用户配置（主题/主色/语言/快捷键/面板拖拽/预设样式/插件启停与配置/最近文件…） | `%APPDATA%\AIDEA\Local Storage\leveldb\` | renderer `localStorage`（`aidea-*` 键） |
| 插件目录 | `%APPDATA%\AIDEA\plugins\` | 生产插件根，启动扫描 + 目录监听 |
| 运行时语言包 | `%APPDATA%\AIDEA\i18n\` | 生产运行时 i18n 根，热登记 |
| 项目文件（白板内容 `.aidea.json`） | 用户「打开/另存」对话框自选路径 | 不落 userData；路径记忆在最近文件列表 |

## 5. 给已安装版本添加一种语言

只放语言包文件，无需改码/重启/重编译：

1. 打开目录 `%APPDATA%\AIDEA\i18n\`（Windows）。
2. 复制 `en-US.json` 当模板，改成目标语言：文件名 = `<id>.json`，顶部 `@meta` 保持 `id` 与文件名一致、`label` 用该语言自名、`naiveBase` 选 naive-ui 内置语言（缺省 `en-US`）；正文与 `zh-CN.json` 的 key 同构，漏掉的 key 自动回退中文。
3. 保存后**自动登记**，无需重启，"设置 → 外观 → 语言"下拉立即可选；覆盖/删除文件同样即时生效。

非法包（无 `@meta` / id 不符 / JSON 损坏）被静默跳过，不影响程序。详见 `追加语言.md`。

## 6. 给已安装版本添加一个插件

已安装的正式版插件扫描根是 `%APPDATA%\AIDEA\plugins\`：

1. 建目录 `%APPDATA%\AIDEA\plugins\<id>\`，目录名即 pluginId，强校验 `^[a-z0-9_-]+$`（非法子目录被跳过）。
2. 放入入口文件 `plugin.js`（或 `index.js`/`index.mjs`），可选放 `manifest.json`。
3. 启动时自动扫描发现；已运行的应用在「设置 → 插件」点「重新加载」后生效（无需退出）。

内置 AI 插件（`plugins/ai/`）与第三方插件同级，地位一致。开发插件用宿主 SDK 见 `插件开发手册.md`，架构见 `插件系统.md` / `Electron桌面架构.md`。
