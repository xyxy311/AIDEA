# 可拖拽面板与左右侧边栏（dock）

右侧边栏采用 **PS / Blender 式多面板 dock**：在固定宽度侧边栏内垂直堆叠多个面板，面板间有可上下拖拽的分隔条调整各自高度，面板本身可拖拽换位、可关闭；且面板可在**左侧活动栏**与**右侧 dock** 之间互通拖拽移动。

设计思想：**所有面板地位等价**，都能进左侧或右侧，只是布局层管理不同（左侧单面板区 / 右侧多面板 dock）。面板本身只写内容，统一由 `DockPanel` 外壳承载标题栏 / 图标 / 关闭 / 拖拽 / 边距。

## 布局模型

```
┌─────────────── MenuBar ───────────────┐
├ ActivityBar ┬ LeftSidebar ┬ Toolbar ┬ RightSidebar ┤
│  (图标栏)    │ (单面板区)   ├ Canvas ─┤  (多面板 dock)│
└─────────────┴────────────┴──────────┴──────────────┘
```

- **左侧**：`ActivityBar`（48px 图标栏，始终可见）+ `LeftSidebar`（单面板区，激活 `activePanelId` 决定显示哪个面板）。VSCode 风格，但面板同样由 `DockPanel` 包裹（带标题栏 / 关闭 / 拖拽手柄）。
- **右侧**：`RightSidebar`（可收起/展开、可调宽度）内部渲染 `DockContainer`，垂直堆叠多个由 `DockPanel` 包裹的面板。

## 组件分层

| 组件 | 路径 | 职责 |
| --- | --- | --- |
| `DockPanel` | `components/common/DockPanel.vue` | **唯一面板外壳**（两侧共用）：标题栏显隐 `showHeader`、活动栏图标（品类表同源）、标题、关闭 `showClose`、拖拽手柄 `draggable`、滚动 `NScrollbar x-scrollable`；内容组件从品类表 `component` 读取 |
| `DockContainer` | `components/common/DockContainer.vue` | 右侧垂直堆叠 + 分隔条 resize + 换位 reorder + 跨容器 drop zone + 空态 |
| `LeftSidebar` | `components/layout/LeftSidebar.vue` | 左侧单面板区外壳：渲染激活面板的 `DockPanel` |
| `RightSidebar` | `components/layout/RightSidebar.vue` | 右侧外壳（收起/宽度），内容渲染 `DockContainer` |

## 面板品类表（constants/panels.ts）

面板定义集中在一个全量品类表 `PANEL_CATALOG`（单一数据源），**不区分左右**：

```ts
interface PanelDef {
  id: PanelId
  titleKey: string               // 标题 i18n key
  icon: Component                // 活动栏 + 面板标题栏共用图标
  component: Component           // 面板内容组件（纯内容，无 header）
  defaultPlacement: 'left'|'right' // 默认放置侧
}
```

派生导出：`PANEL_INDEX`（id→def 快速索引）、`PANEL_COMPONENTS`（id→组件）、`DEFAULT_LEFT_PANELS` / `DEFAULT_RIGHT_PANELS`（由 `defaultPlacement` 派生，取代旧的 `DEFAULT_RIGHT` 硬编码）。

**新增面板**：只需在 `PANEL_CATALOG` 登记 `id + titleKey + icon + component + defaultPlacement`，活动栏图标、左侧面板区、右侧 dock、左右互通、默认布局全部自动生效。

## 面板纯化约定

`panels/` 下的面板组件是**纯内容组件**：
- **不携带** `header` / `hideHeader` prop / `title` / `defineExpose({ title })`。
- 标题、图标、关闭按钮、拖拽手柄、边距、滚动全部由外层 `DockPanel` 提供。
- 面板内的操作按钮（如 NodeTreePanel 的新建 / 删除）作为面板内容自身的顶部工具栏保留，不归外壳管。

## 数据模型（layout store + utils/dock.ts）

面板归属用「左侧 ∪ 右侧 ∪ 未放置」三态：

```
leftPanels: PanelId[]                // 左侧活动栏顺序（= panels，单面板区）
rightPanels: PanelId[]               // 右侧 dock 顺序
rightSizes: Record<PanelId, number>  // 右侧各面板高度比例（flex-grow）
```

**约束**：一个面板同一时刻只能归属一侧。`utils/dock.ts` 提供纯函数做状态转换与派生（`deriveDockLayout`/`parseDockDelta`/`reorderSeq`/`dropSize`），可单测；`layout store` 只做薄封装 + 持久化。

**默认布局**：由 uiRegistry 登记表的 `defaultPlacement` 派生（`layout.leftPanels`/`rightPanels` 实时派生目录），不硬编码。

**delta 持久化**：localStorage（`aidea-dock-left` / `aidea-dock-right` / `aidea-dock-sizes` / `aidea-dock-removed`）只存「用户显式改动」（顺序覆盖 / 跨侧移动 / 关闭 = `removed` / 尺寸）；加载时 `parseDockDelta` 清洗；渲染目录由 `deriveDockLayout` 实时派生——新增内置面板 / 插件注册自动按默认侧出现，无需归一化补齐。设置面板「恢复默认布局」调用 `layout.resetDock()`（清空 delta）。

## 统一拖拽协议（utils/dock.ts）

所有面板拖拽用 HTML5 drag，读写逻辑集中在 `utils/dock.ts`（ActivityBar / DockContainer / LeftSidebar 复用，不再各自实现）：

```ts
writePanelDrag(e, { panelId, from: 'left' | 'right' })  // 写 dataTransfer
readPanelDrag(e)                                        // 读并容错解析，返回 null 表示无效
PANEL_DRAG_MIME                                         // 'aidea-panel'
```

## 交互行为

- **同容器换位**：右侧面板 header 拖拽到另一面板位置 → `layout.reorderRight(from, to)`；左侧活动栏图标拖拽排序 → `layout.reorder`。
- **跨容器移动**：
  - 右侧面板拖到左侧活动栏 → `layout.moveToLeft(panelId)`（加入左侧末尾并激活）。
  - 活动栏图标 / 左侧面板拖到右侧 dock → `layout.moveToRight(panelId, toIndex)`（从左侧移除，若为当前激活则收起左侧）。
- **分隔条 resize**：pointer events，按住面板间分隔条上下拖，保持相邻两块 flex 之和不变按 delta 分配，`layout.setRightSize`。
- **关闭面板**：DockPanel header 关闭按钮 → `layout.removePanel(panelId)`（从两侧移除，回到「未放置」）。
- **添加未放置面板**：活动栏底部「+」弹出浮层列出未放置面板，点击 → `moveToLeft`。

## store API 速查

```
layout.panels           左侧活动栏顺序（ref）      layout.rightPanels    右侧顺序（ref）
layout.rightSizes       右侧高度比例（ref）        layout.rightEmpty     dock 是否为空
layout.moveToLeft(id)   右侧 → 左侧               layout.moveToRight(id, idx)  左侧 → 右侧
layout.reorderRight(a,b) 右侧内换位               layout.setRightSize(id,flex) 设高度
layout.removePanel(id)  移除回未放置              layout.resetDock()           恢复默认
```
