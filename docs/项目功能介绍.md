# AIDEA 项目功能介绍

## 功能概况

AIDEA 是一款头脑风暴应用，主要的画布元素为**节点**和**连线**，通过二者的组合来表达想法。节点使用树型结构，每个节点可以有多个子节点。连线则用于连接同一个父级的子节点。

节点可以打**标签**，用于辅助表达用户的想法，也可以作为搜索节点的过滤条件。

此外，**引用**功能允许用户在一个节点中引用其他节点，用来辅助表达用户的想法，并支持快速跳转到被引用节点。需要注意，**可引用节点**的名称以“#”开头，且引用名称唯一；要引用一个节点时格式为“@节点名”（输入 @ 时会有自动补全提示）。

此应用还提供节点/连线**预设**系统，使用数字键即可快速切换选中元素的预设；预设支持分组管理与筛选。

一些操作可由键盘完成：方向键移动节点、Enter 编辑、Delete 删除、A 进入子视图、Q 返回上级等。**网格模式**允许用户将节点和网格对齐，开启后更可完全脱离鼠标，通过网格焦点移动、键盘连线等方式编排节点。

**视图**展示当前正在观察的节点的下一级内容（直接子节点及其间的连线）。**主视图**只有一个，**内联视图**可以有多个，每个视图渲染在一个画布上。新建一个项目时，默认会创建一个不可删除的根节点，视图默认观察根节点，但也可以切换到其他节点。

**内联视图**可以将某个节点的子视图直接展开嵌入当前画布，便于就地查看与编辑（仅支持一层嵌套）。

**标签页**允许用户快速切换到其它节点的视图，方便用户查看和管理节点。

多个节点可以**组合**为一个容器节点，作为整体移动与管理。

项目以 `.aidea.json` 文件保存，支持新建、打开、保存、另存为。界面支持明暗主题与中英文切换，侧边栏面板、顶部按钮与快捷键均可自定义调整。

项目还支持**插件系统**（目前未实现完毕），**AI功能**以插件的形式存在，内置“AI 发散”功能，支持 OpenAI 兼容接口与 Ollama 本地模型。


## 页面布局

- 顶部栏有三部分，左右两侧为功能按钮（可拖拽移动位置），中间为标签栏
- 中间为画布区域
- 左侧为活动栏 + 可收起面板，右侧为多面板。两侧面板互通，可拖拽放置
- 还可以弹出模态面板和浮动面板
